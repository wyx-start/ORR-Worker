# 使用指南

## 打开与关闭

双击应用文件夹内的 `启动 ORR.cmd`，浏览器会自动打开。再次双击会复用现有服务。需要结束后台服务时双击 `停止 ORR.cmd`。

## 第一次处理数据

1. 打开「导入与设置」，拖入 TXT 并点击导入。每批约 10 个文件即可。
2. 检查表格中的用途、转速、分组和背景。相同电极、相同实验条件下的多转速文件设为同组，背景用途设为“背景”。表格修改先进入本批草稿。
3. 查看「当前实验条件」，展开「修改实验条件」填写带 `*` 的必要项目。先选读取来源，再核对“仅此文件／当前组／自选”的应用范围。默认当前组；切换来源和范围本身不复制条件。实际修改任一条件时，会把当前显示的整套条件暂存到明确目标。需要原样复制已显示条件时，点击“复制当前条件到所选范围”。
4. 如果只是先查看原始坐标曲线，把侧栏电位坐标改为“原始”，也会加入同一草稿。正式 RHE 图需有效的换算条件。
5. 在「扫描与背景」核对方向与背景。默认选最后完整循环中的电位递减支线；A／B、人工选段、通道、符号和 iR 位于高级区。所有科学设置统一暂存。
6. 核对“查看本次修改与目标文件”，点击一次「应用设置」使本批草稿生效；也可直接进入分析页使用「应用并计算」或「应用并导出绘图 CSV」。
7. 在「极化曲线」先选盘／环和本次文件，再查看有关条件和结果。颜色、图例、单位、平滑等绘图选项即时更新。

## 草稿、应用与结果状态

实验条件、身份／分组、转速、扫描、通道、背景、背景 pH 与全局电位坐标先进入共享草稿。切换页面、来源、范围或收起高级区不会偷偷应用；原目标上的草稿也不会转移给新目标。状态区区分已应用条件与待应用修改，可查看目标和字段，也可选择“放弃未应用修改”。

“应用设置”统一校验并提交文件配置和全局设置。非法数值、通道或绑定会阻止应用并保留错误，避免半更新；缺 pH、缺 N 等合法但尚不可分析的记录允许应用和保存项目，真正使用这些参数的计算／导出仍会说明缺项并阻止。共享背景 pH 冲突也可作为待解决记录保存，依赖该背景的分析必须先解决。

有草稿时，可直接使用“应用并计算 K–L／RRDE”“应用并导出绘图 CSV”或“应用并保存项目”。组合分析／导出先校验所选任务，失败不下载旧文件；项目保存允许保留缺项和冲突记录。设置提交成功但后续任务失败时，以页面提示为准，修正后重新计算。科学设置更新会使旧结果失效；只改颜色、单位或显示平滑不会清除有效的 K–L／RRDE 结果。

## 从文件名预填转速

以下名称可自动预填 1600 rpm：`CoPc_1600转.txt`、`CoPc_1600 RPM_测试.txt`、`CoPc_RPM1600.txt`、`CoPc_转速=1600.txt`。转速可位于名称中间，空格和英文大小写均可处理。

原有 `O-0.1MNa-5mv-900.txt` 仍能预填 900，但来源标为“末尾数字推测”，请注意数字也可能是编号。不要把推测值当成已经核对的实验信息。

同名中的明确转速若冲突，例如 `CoPc_900转_1600转.txt`，转速保持空白并提示手填。小数转速名称不自动拆取整数，rps 不自动转换；需要时可手工输入正确 rpm。`0转` 用于静止数据，不能用于 K–L 拟合。

表格中的“转速来源”只读；展开“转速识别依据与需要核对的记录”可看完整依据。样品/图例名称可编辑，但不会反过来改转速。不同转速的默认分组会去掉转速片段，仍需核对实验是否真的同组。

手动改值后统一“应用设置”。人工数值优先，重复导入和恢复项目会保留它。需要补齐先前未识别的记录时，点击“根据文件名补全空白转速”；结果进入本批草稿，只补当前候选中的空白，不改非空值和分组。应用有实际数值变化的草稿后，旧结果清空，请重新计算。

旧项目会保留原有转速（包括空白），不会因更新程序自动覆盖；来源显示“项目保存值（来源未记录）”。可再主动补全空白。保存新项目或参数 JSON 时，识别来源、匹配片段和候选会一起保存。

## 电位参数怎么填写

三种方式选择一种：

- **理论换算**：填写 pH、核对温度（默认 25 °C），选择参比方案。选择内置预设后无需再填参比电位；自定义时才显示名称、内充液及 E_ref vs SHE。
- **实测 RHE 总偏移**：输入实际标定的总偏移。程序只加一次，不再加 pH 修正。
- **已是 RHE**：文件电位已经换算时使用，避免二次换算。

选定一种方式后，其他方式的输入不显示，也不被清空。实测总偏移允许 0 V。缺少 RHE 条件时，可把侧栏坐标改为“原始”再统一应用。选择原始电位、mA 电流时，不需要填写 pH、面积或 N。

输入后的值先进入本批草稿。摘要同时保留已应用值和待修改值；曲线可展示标明“未应用”的候选预览，正式计算与下载通过统一应用流程。保存预设时，有草稿则显示“应用并保存预设”，校验通过后保存新值。

1.4.0 起，提交新背景关联后，默认沿用对应样品已应用的 pH。先绑定背景再填写样品 pH 也会同步，无需专门把背景加入参数应用范围。共享背景出现多个不同 pH 时会明确提示冲突。

理论 RHE 仍需背景实际的参比和温度。其他条件也相同时，在“自选”范围中明确加入背景再修改或复制条件；不同条件可在“读取设置的文件”中选择背景单独设置。

## 背景 pH 跟随与独立模式

新背景为空时，选择背景并提交绑定后即采用样品 pH；后续应用新的样品 pH 会更新背景。只改输入框草稿不会更新。pH 为 0 是有效值，不会被当成空白。

在“扫描与背景”选择使用该背景的文件，展开“背景 pH · 文件名”核对：

- “跟随关联样品”：使用全部已填写关联样品的一致 pH。未填的样品仍需填写；软件不反向补样品。
- “独立填写”：输入背景实际值，统一“应用设置”后生效，之后不会被样品修改覆盖。
- 背景已有独立值或来自旧项目时保留原值；即使与样品不同也不会自动改写，请按实验记录选择模式。
- 同一背景被多个样品共享时，模式影响所有关联样品。不同 pH 产生跟随冲突时，核对条件或更换适用背景；软件不会任选首末值。
- 更换或移除文件会更新来源；最后一个关联被解除后，自动派生 pH 清理，独立值保留。

仅 pH 联动，电解液气氛、参比、温度、实测偏移、面积和 N 不自动复制。项目与参数会记录生效 pH、模式、来源和冲突状态。

同一批不同条件可分组选择文件，核对范围后统一“应用设置”。电解液文字记录在选填区；不要把不明确的文件名当成实际 pH。

## 默认面积与必填标记

`*` 表示当前操作必填，已经用默认值或预设填好的项目可直接使用。切换用途后，必填项会改变：盘面积用于电流密度和 K–L，N 用于 RRDE；它们不阻塞普通 mA 曲线。

新文件默认盘直径为 **5 mm**，圆盘几何面积约 **0.19635 cm²**。选择电流密度或进入 K–L 后，展开条件即可改盘直径；面积会同步计算。也可选择“直接输入面积”，输入 cm²。计算和导出保留未舍入数值。面积是盘几何面积，不是环面积或电化学活性面积，不能由此推定 N。

已有项目的面积优先，旧项目原本为空仍保持为空，不会被升级后的默认值覆盖。缺失或错误面积仅影响需要面积的操作，原始电位 mA 曲线仍可查看。

## 保存常用实验条件

展开“常用条件：保存与复用”，载入与保存分开操作：

- 选择预设后点击“载入预设到草稿”，默认只补空白和软件初始默认，不改已有人工参数。覆盖非空值需勾选对应选项，并核对目标文件；载入后仍可手改，最终统一应用。
- 保存使用一个入口，位置选择“当前项目”或“本机”。当前项目预设随 `.orrproj` 保存；本机预设写入 `user_settings/experiment_presets.json`，重启后可主动选用。同名保存会更新。
- “保存预设”读取来源文件的整套可复用条件。有科学草稿时变为“应用并保存预设”，统一校验和提交后保存；来源不在目标范围时，不会因此修改来源文件。
- 预设不复制样品名、转速、扫描段、具体背景绑定或“已核对”状态。不同组和背景不会被静默覆盖。

若只编辑了来源之外的目标文件，需保存这些新条件时，先把读取来源切换到该目标文件，再保存预设。

本机预设损坏会提示并保留原文件，可继续手工设置或载入项目。当前会话仍需下载项目保存，常用预设不等于保存全部分析数据。

## 只对比多个样品的环电流

1. 在“扫描与背景”核对各 RRDE 文件的盘/环接线映射；背景文件用途设为“背景”。
2. 进入“极化曲线”，把“绘制通道”切为“环电流”。按组筛选选择“全部”可跨组勾选不同样品，不必修改分组。
3. 默认绘制处理后的环电流，单位 μA；可切 mA 或“未扣背景”。原始正负号保留，不除以 N。横轴是盘扫描电位，固定环电位仅作记录。
4. 查看“环电流比较条件”：转速与环设定电位可不同；其他已知条件冲突会列出原因并停止这次叠加。缺失项允许，但标为未完整核对，不表示已证实同条件。
5. 按需调整平滑、颜色和坐标，在“导出当前结果”下载绘图 CSV；PNG 为次要入口，SVG、完整数据和参数在“更多导出”。文件名为 `ring_current*`，与盘图区分。

普通环图不要求盘面积或 N；理论 RHE 仍需有效 pH/参比，iR 仍需原始盘通道。只看环电流不受无关盘背景错误阻断；切“未扣背景”也不会解除原绑定或绕过真正参与横轴处理的条件。

CSV 保留原始 A 列、实际参与的背景、所选视图的环电流与绘图值/单位。未参与或未绑定背景标明状态，不把未知背景写成测得零值；未扣背景视图的 `I_ring_corrected_A` 为空。平滑列带 `smoothed_plot_only`，分析仍用未平滑数据。

## 一个盘环文件同时作盘和环背景

新 RRDE 默认“盘环配对背景”。在导入表的“背景文件”选择一个双通道背景；或者进入逐文件“扫描与背景”，选择“背景文件（盘扣盘、环扣环）”。统一应用后，同时建立样品盘扣背景盘、样品环扣背景环两条关系。普通配对界面只需选择一个背景。

映射采用各文件已保存的逻辑盘/环通道，接线反向时先在高级设置中修正。单通道背景不能作为完整盘环配对背景，可在高级区改选“分别指定背景”，单独设置盘或环，也可只解除其中一条。配对模式选择“不扣除”并应用则同时解除两条关联。

旧项目保留原盘、环背景及独立模式；只有主动选择配对并应用才替换。配对同一背景的 pH 仍按已有规则联动且去重，参比等其他参数不自动复制。修改科学输入后旧结果失效，请重新生成。

## 极化曲线平滑

在「极化曲线」打开“启用曲线平滑”。此功能只修改绘图用的副本，K–L 和 RRDE 继续使用未平滑电流。

- 弱：11 点；中：21 点；强：51 点。默认弱，平滑总开关默认关闭。
- 自定义：填写 5–1001 的奇数窗口。二阶多项式固定，不需要设置算法细节。
- 同张图所有选中曲线使用相同点数。下方表格显示各曲线的实际窗口电位跨度。
- 默认同时显示浅色未平滑参考线，方便检查细节；可关闭参考线。
- 窗口过大可能抹掉细节，端部也可能改变。建议先从弱开始并比较参考线。
- 缺口保留；太短或电位不等间距的段会保留未平滑曲线并说明原因。开启 iR 后电位可能不等间距，程序不会为了平滑自动重采样。

PNG/SVG 对应当前显示。“绘图 CSV”导出当前实线使用的数值，开启平滑时列名带 `smoothed_plot_only`；“完整数据 CSV”另保留未平滑列、绘图列和逐点状态，说明哪里实际平滑、哪里保留原值。参数与项目保存所选设置。修改平滑不会清空已有 K–L/RRDE 结果。

## K–L 分析

核对各文件转速和盘面积（新文件默认 5 mm），将相同条件的文件放在同一组。进入「多转速 K–L」，每个转速选一条曲线，先查看“核对实际参与计算的文件参数”，再选择“电解液参数方案”。可一次选用适用的文献方案，或在自定义方式下填写 C、D、ν。

初始分析范围是共同电位覆盖范围、30 个点；“分析区间与点数”默认展开。共同覆盖不代表整个区间适用 ORR 分析，请结合各转速曲线和实际反应选择电位，避开电流过小、反向或其他反应区，不要根据 n 是否落在 2–4 内反推分析区间。原始坐标与 RHE 下的电位数值不同，结果提示和导出参数会记录本次坐标。

C 为溶解氧浓度，单位 mol/cm³：若来源为 mol/L，需除以 1000。D 和运动黏度 ν 都使用 cm²/s：来源为 m²/s 时需乘以 10000；ν 的来源若为 cSt，需乘以 0.01。动力黏度不能直接填入 ν。物性输入框旁提供单位帮助。KOH 文献方案须核对其电解液、温度及氧饱和条件。

点击“计算 K–L”；有共享科学草稿时，按钮显示“应用并计算 K–L”，会先核对所选任务能否使用候选配置。全部选中文件必须参与，某个转速处理失败不会被静默删除后继续拟合。计算后查看“本次结果使用”的物性及区间，并检查异常点提示和 `status`。超出范围的原始数值保留；负数或超过 100% 的模型比例不能作为有效选择性。分析输入变化或新计算失败会使上一轮结果与相应导出失效。

物性单位分别是 mol/cm³、cm²/s、cm²/s。内置 KOH 参数只适用于所标注的 O₂ 饱和 0.1 M KOH、25°C 条件，不能直接套到 NaOH 或其他浓度。

点击计算后，可查看 n、电位逐点拟合、模型下的 2e/4e 比例，下载结果与拟合点。两转速提示无法有效评估线性，建议三个以上。图中的“模型估算”标记应保留。

## RRDE 分析

在导入页「扫描与背景」核对 i1/i2 的实际接线：默认 i1 盘、i2 环，但可以交换。在 RRDE 页展开实验条件填写本电极的收集效率 N（0–1，无通用默认值）；导入页可记录环材质和固定电位，确认该环条件能定量检测过氧化物。未确认时保留核对警告。RRDE 比值不要求填写盘面积。

盘、环背景可以配对或分别选取；没有环背景时标明未扣除。先在 RRDE 页面选择本次文件，核对条件，点击“计算 RRDE”或“应用并计算 RRDE”，再查看过氧化物产率、n 和两产物模型下的 4e 比例。单个失败文件报告原因，可用文件继续；改变文件选择、阈值或科学设置后需重新计算。

符号错误、盘电流太小或背景不覆盖的点会给出原因；超出 0–100% 等模型范围的数值不会强行修正。可查看异常点表格，再返回参数页核对。

## 保存与导出

分析页优先提供“下载绘图 CSV”，旁边提供 PNG；SVG、完整数据、参数与当前结果包位于“更多导出”。多图分析可在此选择需要的图片。CSV 使用 UTF-8 BOM、逗号分隔、首行列名，无额外说明行或索引，可导入 Origin 后指定 X／Y 列。

- 极化／环图：每条样品一组独立 XY 列，名称包括样品、稳定短 ID、变量、单位及电位坐标。各样品使用自己的电位网格，点数不同只在短列末尾留空，内部缺口保留。不会为对齐新增插值、截短或重采样。
- 绘图 CSV 跟随当前盘／环通道、选中文件、单位、背景显示和显示平滑，导出当前实线数值。浅色未平滑参考线不替代实线。平滑只用于绘图，K–L／RRDE 结果仍由未平滑数据计算。
- K–L：结果 CSV 使用共同电位列；拟合绘图表每个分析电位一组 X=`omega^-1/2`、Y=实测 `1/j`、Yfit=拟合值。完整拟合点长表独立保留。
- RRDE：每条样品一组电位、过氧化物率、电子数和四电子模型比例列。异常值、缺口和超出模型范围的数值保留，完整表另有原因及有效性字段。
- 完整数据 CSV：保留原始／当前电位、原始／实际背景／处理后电流及状态。缺失或未参与背景通过状态区分，不把未知背景写成测得的零值。
- PNG 为 300 dpi；SVG 可继续编辑，换电脑时留意中文字体。JSON 保存参数、来源、表头、文件 SHA、本次选择及处理记录。
- 结果 ZIP 保存当前有效的已生成产物；`.orrproj` 保存原始 TXT 与已应用设置，用于恢复继续编辑，两者用途不同。

## 常见提示

| 提示 | 操作 |
|---|---|
| 缺 pH / 参比电位 | 补参数，或暂时使用原始坐标 |
| 没有完整循环 | 查看扫描段；切 B 或手选，并核对末圈是否确实截断 |
| 背景未覆盖 | 更换背景，或只分析覆盖的区间；程序不会外推 |
| 参比坐标不一致 | 正确换算到 RHE，或分别处理 |
| 缺盘面积 | 补面积后再画电流密度或做 K–L |
| 缺收集效率 N | 输入实际标定值；不能填百分数 37 代替 0.37 |
| 环电流方向异常 | 核对通道、符号、背景和环检测条件 |
| 非单调校正电位 | 核对 iR 设置是否重复或电阻过大 |
| 平滑段太短 | 保留原曲线；可主动选择更小的窗口 |
| 平滑提示电位不等间距 | 保留原曲线；核对采样或 iR，不会自动重采样 |
| 无法启动 | 查看 `.runtime/server.log`，确认本机 Python 路径和依赖 |
