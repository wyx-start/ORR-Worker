# 任务：简化实验条件填写，增加默认选项与必填标记

状态：用户已确认并完成，交付版本 1.3.0。

创建日期：2026-10-15。基于版本：1.2.0。

确认与完成日期：2026-10-15。用户补充并确认以直径 5 mm 的 RDE 作为默认盘几何尺寸。

## 1. 目标

让不熟悉 Python 和软件参数的使用者，导入文件、核对识别结果后，只填写当前分析真正需要的条件。常用设置可以重复使用；必填项、默认项和需要核对的实验信息有明确区别。

保留现有 Windows 双击启动、每批最多 10 个文件、扫描段选择、背景处理、平滑、K–L、RRDE 和分别导出功能。本任务调整输入组织、默认配置和校验提示，不改变科学计算公式。

本文保留确认时的设计与验收规则，实际完成情况见第 12 节。

## 2. 当前问题

- 公共条件表单同时显示 pH、参比、参比相对 SHE 电位和实测 RHE 总偏移，即使所选换算方式不需要其中部分参数。
- 绘制电流曲线时，也会看到盘面积、RRDE 收集效率等其他用途的输入。
- 逐文件设置将扫描段、通道、环信息、背景和 iR 补偿同时展开，常规操作容易被高级选项淹没。
- 部分空白输入缺少清楚的必填条件，用户难以区分“现在必须填”和“做另一种分析才需要”。
- 现有条件预设主要随项目保存，首次处理另一批同类实验时仍有重复填写。
- 批量应用必须更明确地区分同组样品和其他实验条件，避免为了减少输入而覆盖已有人工设置。

## 3. 界面方案

### 3.1 按页面用途显示条件

沿用现有页面导航，根据当前页面及选项显示所需参数，不新增一个必须填写的“任务类型”表单。

| 当前操作 | 默认显示的实验条件 | 额外条件何时出现 |
|---|---|---|
| 导入与核对 | 文件识别结果、样品分组、转速来源、背景候选、当前常用条件摘要 | 点击修改某文件或修改实验条件时展开 |
| 绘制极化曲线 | 电位坐标、对应的电位换算条件、纵轴类型 | 选择电流密度时显示盘面积 |
| K–L 分析 | 同组文件及转速、盘面积、电解液参数方案 | 选择自定义方案时展开 C、D、ν |
| RRDE 分析 | 盘/环通道摘要、收集效率 N、环检测条件核对状态 | 修改通道、符号或环检测信息时展开详细设置 |

切换页面或分析方式只改变显示和校验范围，不清空已经输入的条件。条件摘要始终可以展开查看和修改。

### 3.2 基础条件与高级设置

- 基础区：当前用途必需的参数、可直接选择的常用预设、未完成项提示。
- 高级区默认折叠：自定义参比参数、通道与电流符号、人工扫描段、iR 补偿、K–L 自定义常数、低电流阈值等。
- 单通道文件不展示环通道和环检测输入。
- iR 补偿默认关闭；开启后才显示电阻及已有的确认项。
- 扫描段默认自动选择；需要人工调整时展开完整 CV、扫描段列表和选择控件。
- 背景候选在核对表中集中展示，保留人工核对后应用的流程，不因采用常用条件而自动确认背景。
- 平滑设置保留现有规则；展开绘图设置后可调整，不增加实验条件必填项。

## 4. 必填项规则

标签直接显示“参数名 *”，并在表单上方解释“* 为当前操作必填，已由默认值或预设填入的项目可直接核对使用”。不能只用颜色表达必填状态。

“必填”指该操作所需的输入或选择，不代表用户必须手工敲入数值。预设、文件识别和用户保存的配置可以满足输入要求，但来源和核对状态另行显示。

| 场景 | 必填条件 | 不要求额外填写的条件 |
|---|---|---|
| 原始电位 + 电流 mA 曲线 | 有效文件、电流通道、可用扫描段；通常可自动选出 | pH、参比换算参数、盘面积、N、K–L 常数 |
| 理论换算为 RHE | pH、参比方案、温度；自定义参比还需该温度下的 E_ref vs SHE | 实测 RHE 总偏移 |
| 实测 RHE 总偏移方式 | 实测总偏移值，允许有效的 0 V | pH、参比相对 SHE 电位；可作选填记录 |
| 原始数据已是 RHE | 用户选择“已是 RHE” | pH、参比和总偏移 |
| 电流密度图 | 盘几何面积，或可计算面积的盘直径 | RRDE 收集效率 |
| K–L | 至少两个有效且不同的正转速、各文件盘面积、C/D/ν 有效参数方案、已有的同条件确认 | RRDE 收集效率、环检测信息 |
| RRDE 比值与选择性 | 有效盘/环电流、收集效率 0 < N ≤ 1 | 盘面积、K–L 常数；RHE 横轴另按所选换算方式要求条件 |

补充规则：

- 保留默认 RHE 横轴；缺少换算条件时，明确指出缺什么，并提供“先查看原始电位曲线”的选择，不把原始电位标成 RHE。
- 温度默认 25 °C，用户可以核对后直接使用；更换温度时重新检查参比预设的适用范围。
- 参比预设只展示与当前方式相关的内容。选择已有参比预设后展示只读摘要和来源，自定义时才要求填写名称、填充液及数值。
- 环材料、环固定电位及检测确认属于实验解释与核对信息，和数学必填项分开。保持当前“未确认时提示结果仅供核对”的行为，不在本任务中新增强制阻断。
- “*”随当前操作变化。例如面积对 mA 曲线是选填，对电流密度和 K–L 才是必填。

## 5. 默认值与可选方案

### 5.1 软件可以直接提供的默认设置

| 项目 | 建议默认 | 说明 |
|---|---|---|
| 电位横轴 | RHE | 沿用现有默认；提供原始电位选项 |
| RHE 换算方式 | 理论换算 | 已保存的用户选择优先；不能因此假定参比类型或 pH |
| 温度 | 25 °C | 标明“默认值，请按实验核对” |
| 盘几何尺寸与面积 | 盘直径 5 mm，面积约 0.19635 cm² | 用户指定的默认 RDE 尺寸；支持改直径或直接输入面积，不覆盖已有配置 |
| 扫描提取 | A 模式、最后一个完整的递减电位扫描段 | 沿用现有算法，保留 B 模式和递增方向选择 |
| 纵轴 | 电流 mA | 首次画图不强迫用户填写面积；保留电流密度选择 |
| 转速 | 文件名识别结果 | 沿用 1.2.0 规则，冲突或缺失则留空 |
| 通道与电流符号 | 沿用现有自动建议 | 用摘要显示，允许修改；建议不等于已确认仪器接线 |
| 绘图平滑 | 默认关闭 | 已保存的设置优先；平滑仍只作用于显示 |
| iR 补偿 | 关闭 | 开启后再填写电阻并核对 |
| K–L 分析区间 | 所选有效曲线的公共电位范围 | 保留人工修改 |
| K–L 电位点数 | 30 | 放入高级设置 |
| RRDE 最小盘电流阈值 | 1×10⁻⁹ A | 沿用现有默认，放入高级设置 |

盘面积按圆盘几何公式计算：`A = π × (d / 20)²`，其中 d 的单位为 mm，A 的单位为 cm²。默认 d = 5 mm 时，A = π × 0.25² ≈ 0.1963495408 cm²；界面可显示为 0.19635 cm²，计算及导出保留计算精度。

默认值用于新文件没有既有面积或电极配置的情况，界面标明“默认：5 mm RDE”。电流密度和 K–L 可直接使用该默认面积，无需再次手工填写。修改直径时同步计算面积；选择直接输入面积时以该面积为准，明确标为自定义面积，不继续展示成默认 5 mm 电极。已有项目、用户预设或人工填写的尺寸/面积优先，不被本次新增默认值覆盖。这里的面积指盘几何面积，不是环面积或电化学活性面积；该默认尺寸不推定 RRDE 收集效率 N。

### 5.2 仍不提供通用数值的实验条件

| 项目 | 首次使用 | 减少重复填写的方式 |
|---|---|---|
| pH | 留空，理论换算时标为必填 | 从用户保存的同类实验条件读取；不从 `0.1MNa` 等不明确名称推定 |
| 参比类型及填充液 | 未选择时提示选择 | 提供已有 Ag/AgCl、SCE、Hg/HgO 等预设及自定义选项；保存常用选择 |
| RRDE 收集效率 N | 留空，RRDE 时标为必填 | 从用户保存的对应电极配置读取；不将示例 0.37 作为默认校准值 |
| 环固定电位 | 优先读取文件表头，缺失则留空 | 显示数值所相对的原始参比，允许修改；不设通用默认电位 |
| 实测 RHE 总偏移 | 留空 | 保存并复用用户对应实验的标定值 |

参比的现有数值预设及其来源沿用当前实现。25 °C 预设不能在其他温度直接标为适用；Hg/HgO 预设仍明确为文献近似值，不冒充用户实测标定。

### 5.3 K–L 参数用方案选择替代重复填写

- 提供“已有文献方案”和“自定义”两类选择。
- 已有方案沿用软件当前的“O₂ 饱和 0.1 M KOH、25 °C”近似参数：C = 1.2×10⁻⁶ mol/cm³、D = 1.9×10⁻⁵ cm²/s、ν = 0.01 cm²/s。
- 用户选择并确认适用后，一次填入三项，常规界面只展示条件摘要、数值和来源；详细修改入口折叠。
- 未识别电解液时不自动套用 KOH 方案。NaOH、其他浓度或其他温度不能因方便填写而自动采用该方案。
- 自定义时三项分别标为必填，并保留来源记录。
- 本任务不新增未经核实的电解液数值预设。

## 6. 常用实验条件复用

在现有项目内预设基础上，增加可选的“设为本机常用条件”，解决不同批次和重启后的重复填写。

1. 用户完成一次配置后，可主动保存为本机常用条件。默认名称可用“常用条件”，不增加必须命名的步骤；需要多套时可另存命名。
2. 导入下一批时提供套用入口，显示条件摘要和应用范围；不跨不同实验组静默覆盖。
3. 预设只保存实验参数、参数方案与来源，不保存原始电流数据、样品名称、转速、扫描段编号或具体背景文件绑定。
4. 背景确认、同条件确认、环检测确认等人工核对状态不作为“新文件已核对”的证据自动继承；新批次仍需核对。
5. 已保存项目和当前人工设置优先。套用预设默认只补空白；覆盖非空值时提供明确的覆盖选项和目标范围摘要。
6. 内置的软件默认值只在没有现有值时生效。用户主动选择的参比/电解液预设，可以按本次明确选择更新对应字段。
7. 本机预设建议存放于项目目录下 `user_settings/experiment_presets.json`，不依赖账号或联网；预设丢失或损坏不影响项目打开和原始曲线预览。
8. 项目文件与参数 JSON 继续保存本次实际采用的完整条件，不能只保存一个可能日后发生变化的预设名称。

## 7. 批量应用和数据保护

- 默认应用范围为当前文件或用户选中的同组文件；跨组应用需要明确选择目标，不默认覆盖全批。
- 同组共享条件可一次填写、批量套用；每个文件保留独立覆盖能力。
- 仅更新本次操作实际涉及的字段。折叠或隐藏的无关字段不能被空值清掉。
- 切换理论换算、实测总偏移、已是 RHE 时，保留此前填写值，只使用当前方式所需字段。
- 套用常用条件不修改人工转速、样品分组、背景绑定、已选扫描段和平滑配置。
- 对参数保存“当前值 + 来源”，区分软件默认、文件读取、用户预设、文献预设、人工输入和旧项目来源未记录。
- 默认值与自动识别不自动等于“实验已核对”。来源、有效性、核对状态分别表示。
- 科学配置改变后继续沿用现有结果失效机制，避免导出修改前的旧结果。

## 8. 校验与提示

- 在对应字段旁给出简短原因，例如“绘制 RHE 横轴需要填写 pH”“RRDE 需要填写本电极收集效率 N”。
- 当前操作上方汇总未完成项，可定位或展开对应设置；不以后台异常堆栈代替说明。
- 校验按用途执行：缺少 N 只影响 RRDE；缺少面积只影响电流密度和 K–L；其他有效文件仍可继续处理。
- 无关字段的历史空值或无效值不应阻塞原始电位 mA 曲线，但在真正使用该参数的计算中必须严格校验并提示。
- 前端和核心计算层保持一致的有效性检查，不能仅隐藏字段而绕过科学要求。
- 文献方案不适用、转速冲突、扫描段不完整等现有错误继续明确展示。

## 10. 验收用例

| 场景 | 预期结果 |
|---|---|
| 首次导入普通 CV，只预览原始电位 mA 曲线 | 无需填写 pH、参比、面积或 N；自动扫描可用即可预览 |
| 默认 RHE、理论换算但未填条件 | 仅标出 pH 和参比等当前缺失项，提供原始电位预览入口 |
| 选择内置参比预设 | 自动提供对应值和来源，不要求再重复输入 E_ref vs SHE |
| 选择实测 RHE 总偏移 | 只要求总偏移；0 V 可保存，不额外叠加 pH 项 |
| 选择已是 RHE | 不要求 pH、参比或偏移；不再次换算 |
| 新文件从 mA 切换到电流密度 | 显示默认 5 mm RDE、约 0.19635 cm²，面积必填条件已由默认值满足，无需手填 |
| 修改盘直径为 4 mm | 面积同步变为约 0.12566 cm²，计算使用未舍入值；电流密度和 K–L 使用更新后的面积 |
| 选择直接输入自定义面积 | 采用输入的面积并标明来源，不再表示为默认 5 mm RDE |
| 打开已有非 5 mm 电极配置的项目 | 保留已有面积和尺寸，不被 5 mm 默认值覆盖 |
| 已有 25 °C 参比预设，温度改为其他值 | 提示适用性问题，不静默沿用为有效预设 |
| 文件名含 1600转 | 沿用现有识别；套用实验预设不覆盖转速和来源 |
| 做 K–L 并选择适用文献方案 | 一次填入 C/D/ν，保留适用条件和来源；自定义时分别必填 |
| 电解液只有不明确的 Na 信息 | 不自动填 pH，不自动套用 KOH 参数 |
| 做 RRDE、缺少 N | RRDE 明确提示 N 必填，曲线绘制继续可用；不要求盘面积 |
| 环检测未确认 | 保留现有核对警告，不能展示成已确认定量条件 |
| 两组文件有不同条件 | 默认不跨组覆盖；可查看目标并主动选择批量范围 |
| 切换页面或换算方式后再返回 | 原有输入保留，隐藏字段未被清空 |
| 本机常用条件保存后重启 | 可复用数值和来源，但不自动继承新文件的背景/实验核对状态 |
| 打开 1.2.0 的项目并导出参数 | 数值、人工转速和已有设置保持；导出包含实际使用条件 |
| 本机预设文件损坏或缺失 | 给出易懂提示，可继续手工设置和预览 |

实施后运行现有相关测试，补充用途校验、预设优先级、隐藏字段保护和项目恢复的必要测试；通过界面验证必填标记、条件显隐、批量范围和重启复用。仅编写本文档不需要运行计算测试。

## 11. 本次确认范围

确认后按以上方案实施：按当前用途减少输入、提供安全默认与常用选项、标注条件必填项、折叠高级设置、增加本机常用条件复用，并同步项目文档。

按用户指定提供 5 mm RDE 默认盘面积，并标明默认来源、允许修改；pH 和收集效率仍不填入未经用户提供的通用数值。不改动已有计算公式、平滑用途、背景核对和扫描提取规则。
