# 极化曲线：起始电位与半波电位

日期：2026-10-30；版本：1.7.0-dev。用户要求在桌面极化曲线页增加起始、半波电位功能，按现有后台计算与导出路径实施。

## 方法与依据

实现显式的阈值法 E_onset 和平台半高 E_1/2。采用文献使用的 0.1 mA/cm² 作为可修改默认阈值，不将它称为唯一标准。[PNAS 原始论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC9335305/) 使用该阈值并按几何面积归一化。半波基于残余基线到极限电流的半高，依据 [IUPAC half-wave potential](https://goldbook.iupac.org/terms/view/H02722)。

令还原方向电流 `q = I_disk_A × disk_sign × 1000`，单位 mA，基线为 b，平台观测电流为 L。起始目标为 `b + threshold_mA`，半波目标为 `b + (L − b)/2`；默认 b=0，密度阈值通过每个文件实际盘面积转换。不得用绝对值修正错误符号。

当前实现使用常数残余基线，不能拟合随电位变化的电容基线。自动最低 20% 电位区间只是平台候选；至少 5 个连续有效点、平台范围电流跨度／波高≤10%，取电流中位数。以上是明确记录的软件质量规则，不是通用电化学标准。支持手动区间，必须被该文件完整覆盖。

只处理严格单调支线，递增／递减采集顺序等价。用相邻有效观测点线性内插，不外推、不跨 NaN／背景缺口；多个交点或阈值水平段拒绝给出唯一数值。相等判定只使用机器舍入尺度容差，不进行数据平滑。无有效平台仍可计算起始；缺面积仅阻止密度阈值起始，电流半波和原图可继续。

## 界面、处理与记录

- `application/potentials.py` 提供独立分析；`application/curves.py` 仅为盘曲线加入结果表和指标 CSV，保留原绘图 CSV。
- 取处理后的未平滑 `I_disk_A` 和 `E_V`，继承背景、iR、当前电位坐标；显示平滑、显示电流单位不改变指标。原始坐标不能误标为 RHE。
- 设置默认折叠，不增加导入页必填项。绘图后显示结果与失败原因，单独保存 `polarization_potentials.csv`；可选圆点／方点标记，来自未平滑数据。
- 参数 JSON 新增 `analysis_polarization_potentials`；设置位于已有 `settings.plot.potentials`，不改变项目 schema。
- 修改或失败清除旧指标 CSV；非法活动输入阻止项目保存。切回自动方式时，隐藏的错误手动区间不会阻止自动计算。
- 原 K–L、RRDE 及环电流比较不使用这两个指标，也不更改它们的电流或模型。
