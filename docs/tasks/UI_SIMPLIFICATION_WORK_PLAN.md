# 工作计划：ORR Worker 操作与导出简化

状态：**用户已授权实施、验证及上传；1.6.0 已完成实现与审查，157 项自动回归及真实浏览器流程通过。**

基线：ORR Worker 1.5.0。第 1～10 节保留当时确认的设计与验收约定，第 11 节记录最终实现和验证，后续维护应同时阅读。

## 1. 目标与范围

减少处理同一批数据时的重复点击，让常用操作直接可见。保留“导入与设置、极化曲线、K–L、RRDE、导出与项目”五页导航，统一各页的设置位置、状态提示、主操作和下载入口。

CSV 是首要导出格式，优先支持在 Origin 中继续绘图。图片、完整数据、参数和项目仍能分别下载。本次继续面向 Windows 本机、每批约 10 个文件，不增加部署或账号功能。

原任务先完成工作计划；用户随后要求“进行计划并验证后上传 github”，已按此范围实施。科学计算公式保持原样，测试使用独立合成包，不操作用户运行中的浏览器会话。

## 4. 统一设置与生效规则

### 4.1 对象、范围和状态

各分析页按相同顺序组织：**选择文件／组 → 条件与状态摘要 → 修改设置／主操作 → 结果与导出**。

- 保留各页自己的分析选择。跨样品环电流比较不强制采用 K–L 的同组文件选择。
- 编辑器区分“从哪个文件读取条件”和“应用到哪些文件”。选择来源只读取条件，不自动复制到整组。
- 应用范围保留“仅此文件／当前组／自选”，沿用当前组默认；显示目标数量，并可查看文件名单。
- 修改实验条件、身份／分组、扫描、通道、背景、背景 pH 和全局原始／RHE 轴时，先记录草稿；切换页面或收起高级项不丢失草稿、不偷偷应用。
- 始终显示“已应用”“有未应用修改”或“设置已更新，需重新计算”；已保存但暂不可算时附加具体待完成项。有草稿时可查看修改与作用范围，也可明确放弃草稿。
- 修改来源或范围后不得把旧草稿无提示地转移到另一批文件。草稿绑定来源快照、目标 ID 和基础修订号；有冲突时提示处理。

### 4.2 一次应用的含义

统一“应用设置”应完成以下完整过程：

1. 收集本次明确暂存的修改，形成候选配置；独立编辑域对同字段提出矛盾修改时，不能静默按最后一次写入处理。同一编辑器中“载入预设后再手改”的最终值是正常草稿，不算冲突。
2. 校验类型、数值、通道、扫描段、背景绑定和所声明的批量范围。
3. 用候选配置统一计算背景 pH 联动状态，标出共享背景的关联冲突；若接下来计算或导出，再校验该任务实际依赖。
4. 校验通过后一次写入逐文件 `configs`、相关全局 `settings`（包括电位轴）及来源记录，统一刷新修订号和受影响的结果；失败保护和组合操作快照同时覆盖这两部分，不能只回滚逐文件配置。
5. 失败时保留草稿及具体错误，不能留下“盘背景已改、环背景未改”之类半更新。

保留现有“把当前显示的一整套实验条件应用到明确目标”的语义；摘要说明会覆盖哪些字段，不能借 UI 重构暗改成只同步刚编辑的字段，也不能每敲一个输入就复制整组。逐文件的背景、扫描和通道修改仍只作用于各自明确目标。

必填项随任务变化。区分“数值／结构非法”和“记录合法但暂不可算”：前者拒绝提交；后者可应用并保存项目，明确缺项或共享背景 pH 冲突，实际依赖它的计算／导出仍阻断。一个未参与本次任务的文件缺 pH，不应遮挡可用曲线。

### 4.3 应用与下一步合并

| 当前情况 | 主操作文案与结果 |
|---|---|
| 没有草稿，准备 K–L／RRDE 分析 | “计算 K–L”／“计算 RRDE” |
| 有科学设置草稿，准备分析 | “应用并计算 K–L”／“应用并计算 RRDE” |
| 没有草稿，下载当前 CSV | “下载绘图 CSV” |
| 有草稿，直接导出 | “应用并导出绘图 CSV”，通过校验后使用新设置生成 |
| 没有草稿，保存项目 | “保存分析项目” |
| 有草稿，保存项目 | “应用并保存项目”，保存实际已应用的新设置 |

组合操作必须使用同一份输入快照和修订号。“应用并计算／导出”先检查所选任务能否使用候选配置；预检查失败保留草稿，不提交、不下载旧数据。“应用并保存项目”允许保存合法但暂不可算的记录。计算失败不保留伪装成新结果的旧表或旧图。科学结果超出模型范围属于带状态的结果，不因电子数异常而自动裁剪或改参。

应用校验失败时不改配置。应用已成功、随后计算或文件生成失败时，明确说明设置已应用、任务失败及原因；不把已提交的设置又显示成未应用。

**实施前置验证：**当前 Streamlit 1.61.0 支持延迟生成下载，但下载生成与页面重跑可能并行，不能把旧字节交给下载按钮，再期待回调替换。第一阶段须验证“一次点击应用并导出”确实包含最后一次输入，且失败不会下载旧文件。延迟生成函数不能负责修改页面状态；配置提交、输出快照和下载交接必须明确。不得以增加隐藏的第二次确认来声称完成一步操作。

### 4.4 生效与结果刷新

- 颜色、图例、线宽、显示单位、平滑和环图的处理后／未扣背景视图即时更新，只刷新对应绘图及下载。
- pH、参比方式、温度、面积、背景、通道、扫描和全局原始／RHE 电位坐标属于科学配置，显式应用后按现有规则使相关科学结果失效。
- 平滑始终只用于绘图副本，不能进入 K–L 或 RRDE 的科学计算。
- 参数、CSV、PNG、SVG 和结果包必须对应同一份有效结果；失效结果不能继续作为当前结果下载。

## 5. 各页操作安排

### 5.1 导入与设置

- 保留批量拖入、识别预览、核对流程；解析失败的文件显示原因，其余继续。
- 主区显示文件名、样品名、分组、用途、转速及其来源。自动推测与人工确认值继续区分，不能因精简界面自动认定猜测正确。
- 将核对表中的修改和实验／扫描／背景草稿纳入统一应用。人工转速保护、冲突转速留空的既有规则继续有效。
- 新 RRDE 配对模式只显示一个背景文件；高级模式分别指定盘／环。提交前展示盘扣盘、环扣环的实际映射。
- 示例、项目恢复、移除文件和补全空白转速置于文件工具区，保留清楚文案；本轮不改变显式导入和项目替换的含义。

### 5.2 实验条件与预设

- 默认先显示本任务需要的条件和缺项，必填标签使用 `*`；默认值仍标注来源。
- 面积沿用用户指定的标准直径 5 mm RDE 默认，温度沿用 25 °C 默认；不为 pH 和 RRDE 收集效率 N 编造通用默认值。
- 原始电位、理论 RHE 换算、实测总偏移、已经是 RHE 保持清晰区分；切换方式只启用对应字段，不清空其他方式的已存记录。
- 背景 pH 收敛到一个编辑组件，主区显示“跟随样品／独立值／冲突”摘要。只联动 pH，不能顺便复制背景的参比、温度、电解液、面积或 N。
- 预设载入先进入草稿，默认只补空白／软件默认；覆盖人工值需要显式选择。保存预设使用一个入口，再选“当前项目／本机”。
- 预设不夹带样品身份、转速、背景绑定、扫描段或检测确认状态。预设保存遇到草稿时使用统一应用流程，不能另设一套提交规则。

### 5.3 扫描与背景

- 常用区显示扫描方向和背景摘要；A／B 选段策略、人工扫描段、物理通道、符号和 iR 收进高级设置。
- 保留扫描预览和人工选段能力，不因收纳而删除异常文件的修复入口。
- “统一当前组扫描规则”必须显式选择；列明受影响文件和会被清除的人工选段，不能作为批量背景操作的附带效果。
- iR 防重复补偿确认继续保留。旧项目的独立盘／环背景不自动迁移成配对关联。

### 5.4 极化曲线、K–L 与 RRDE

- 极化页盘／环用直接切换；平滑默认关闭，只露开关，开启后露强度，自定义及参考线控制再展开。
- 文件选择先于当前任务的错误列表；未选文件的问题可在全批汇总查看。
- K–L 保留分析区间、物性方案及实际使用参数摘要；不按电子数落在 2～4 的结果自动挑区间。
- RRDE 保留真实 N、盘环通道、符号与检测条件要求；阈值等较低频参数收进高级设置。
- 原本允许继续的单文件处理失败仍单独标出；K–L 的同组检查及每转速取一条规则不放宽，不静默剔除某个转速继续出结论。
- 分析页提供相同位置的“修改设置”，不要求用户返回导入页再来回跳转。

## 6. CSV 优先的导出方案

### 6.1 常用与更多导出

- 首要入口：“下载绘图 CSV”；次要入口：PNG。
- “更多导出”：SVG、完整数据 CSV、参数 JSON、当前结果 ZIP。K–L 拟合点等不同用途的数据按清楚名称独立提供。
- “保存分析项目 .orrproj”独立放置，并保留导出与项目页作为集中入口。结果 ZIP 与可恢复的分析项目不能混为一谈。
- 多图分析使用当前结果／图的明确选择，复用统一下载区，避免每张图重复堆放同一组按钮。

### 6.2 绘图 CSV 排布【Q6 已确认】

极化／环电流使用一个 CSV，每条样品曲线一组独立 XY：

```text
样品A__短ID__E_RHE_V,样品A__短ID__I_ring_uA,样品B__短ID__E_RHE_V,样品B__短ID__I_ring_uA
0.900,1.23,0.895,2.34
0.899,1.25,0.894,2.38
0.898,1.27,,
```

- 每个 X 使用该样品当前处理电位；每个 Y 使用明确的当前变量及单位。不为凑共同横轴而新增插值、截短或重采样。
- 样品点数不同，按各自顺序横向并置，短列仅在末尾留空；数据内部原有缺口保留。不能先删除 NaN 再拼接成连续曲线。
- 保留数值精度、原有顺序和带符号电流；列名含样品名、稳定标识、变量、单位和坐标。重名样品不产生重名列，短 ID 前缀冲突时确定性延长或消重。
- UTF-8 BOM、逗号分隔、无额外索引，首行列名后直接是数值；说明和处理记录不插入数值区。
- 导出区提供简短的 Origin 导入说明。CSV 不承诺自动写入 Origin 的 X／Y 列指定；按独立 XY 列组设置后绘图。

K–L 结果表已有共同分析电位，可保持一个 E 列加电子数、选择性等 Y 列；绘图用拟合表每个分析电位占一组 X=`omega^-1/2`、Y=实测 `1/j`、Yfit=拟合 `1/j` 列，完整拟合点长表另留。保留单位及电位标识，不为导出再次插值。

RRDE 各样品使用独立 E 列及过氧化物率、电子数、四电子模型比例列组。异常、缺口和超模型范围真实值保留，完整表记录原因。

### 6.3 平滑与当前图【Q7 已确认】

- 绘图 CSV 对应当前实线：当前所选文件、电位、通道、单位、背景显示和显示平滑。参考用的浅色未平滑线不冒充当前实线。
- 启用平滑时，列名明确包含 `smoothed_plot_only`，导出区说明“仅绘图平滑”；未实际平滑的短段等仍按现有规则保留原值。
- 绘图代码和 CSV 使用同一个变量选择来源，特别补齐盘图的当前 Y 定义，避免盘／环、mA／μA／电流密度或平滑切换后导错列。
- K–L／RRDE 分析 CSV 仍来自未平滑电流计算的结果，不随极化图平滑开关改变。

### 6.4 完整数据与参数

现有纵向长表保留，名称统一为“完整数据 CSV”，含文件标识、原始／当前电位、原始电流、实际参与的背景、处理后电流及状态。适用时另列显示平滑值，不替换未平滑列。沿用既有处理值与状态：当前盘／完整处理在未绑定背景时可能保存零，环单通道未参与背景时保存 NaN；必须通过状态区分未绑定、未参与和真实零背景，不能凭数值冒称已扣背景。本次不为统一显示而更改核心处理值。

参数 JSON 记录本次选择、单位、轴、背景视图、平滑报告、实际科学输入和修订信息；结果包只收录当前有效产物，且保留每种文件独立下载。

## 7. 实施顺序与交付

| 阶段 | 工作 | 完成条件 |
|---|---|---|
| 0：确认计划与技术验证 | 用户确认整体计划后，验证最后输入、跨页草稿和一步下载的可行性；记录现有常用流程点击次数 | 不以旧文件下载或额外重复点击替代承诺 |
| 1：统一草稿与应用 | 集中草稿、作用范围、候选校验、背景 pH 解析、修订及错误处理 | 四个提交域实际汇入一次应用；无半更新和静默覆盖 |
| 2：整理导入与公共设置 | 设置摘要、预设入口、基本／高级分区、背景配对显示 | 常用条件一次编辑应用，相关高级能力仍可找到 |
| 3：统一分析页 | 先选择文件、按用途显示缺项、组合计算、结果有效性及导出区 | 直接在本页修正条件并完成计算，不反复跳页 |
| 4：CSV 与下载 | 按 Q6／Q7 实现 Origin 绘图表及统一导出；保留完整表与项目 | 下载与当前图／结果一致，不改变原始数据 |
| 5：回归与交接 | 单元／界面／浏览器验证；更新 README、USER_GUIDE、PROJECT、CHANGELOG、VALIDATION | 形成可复核报告和后续维护记录 |

优先使用当前版本 Streamlit 原生控件与统一业务状态；应用草稿不依赖某个隐藏控件是否仍渲染。跨页共享业务状态与控件临时值分开管理，不能仅靠折叠框把提交逻辑藏起来。

## 8. 验收清单

### 操作与状态

1. 10 文件批次中，分组／实验条件／扫描／背景修改可一次应用；先记录现有流程，再对比完成同一任务所需步骤，报告实际减少情况。
2. 来源切换不覆写整组；目标范围可核对；未选文件不被应用；高级项收起和跨页返回不丢草稿。
