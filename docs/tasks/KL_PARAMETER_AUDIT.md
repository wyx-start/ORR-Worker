# K–L 参数与异常结果排查

日期：2026-10-15。基线：ORR Worker 1.4.0；相关修复已并入 1.5.0，并于 2026-10-19 按用户要求同步 GitHub。

用户反馈：可以计算，但电子转移数或选择性异常。尚未取得本次浏览器会话的实际 K–L 参数和结果，当前结论不能替代对该批数据的复现。

## 已检查的参数和计算

- 已核对参数读取、应用范围和单位；本机实际常用条件不随公开文档提供。C、D、ν 应以真实电解液和温度适用的数据为准。
- 原始 TXT 按表头统一换算为 A；两份 RDE 示例的电流单位均为 A。计算使用符号校正后的盘电流除以几何面积，得到 A/cm²。
- rpm 在程序内转换为 ω = 2π rpm / 60，单位 rad/s；拟合 1/j 对 ω^(-1/2)。n 为斜率与 0.62 F D^(2/3) ν^(-1/6) C 乘积的倒数。
- C 单位为 mol/cm³，指溶解氧浓度；D 和运动黏度 ν 的单位为 cm²/s。mol/L 转 mol/cm³ 需除以 1000；m²/s 转 cm²/s 需乘以 10000；1 cSt = 0.01 cm²/s。动力黏度不能直接作为 ν 输入。
- KOH 预设值为 C=1.2e-6、D=1.9e-5、ν=0.01，适用说明为 O₂ 饱和 0.1 M KOH、25 °C。不能据此认定适用于文件名中的 Na 电解液。
- 当前初始分析范围是曲线整个共同覆盖区间，未自动识别适用的 ORR 反应区间；它可能包含电流过小、反向或不满足模型的点。
- n 超出 2–4、负截距或斜率非正等情况会标记模型检查未通过。原始模型比例保留，因此可能小于 0% 或大于 100%；此时不能作为有效选择性。

公式核对来源：[Pine RDE theory](https://pineresearch.com/support-article/rotating-disk-electrode-rde-theory/)、[Pine K–L analysis](https://pineresearch.com/support-article/koutecky-levich-analysis-rde/)。物性预设来源：[Nature Communications 2024](https://www.nature.com/articles/s41467-024-50377-y)。

## 区间与参数敏感性检查

开发环境曾用本地文件检查扫描方向、背景和电位区间对拟合的影响；原始文件、实测衍生数值及本机验证 CSV 不在公开仓库中提供。

公开可复现验证使用构造的已知答案数据：n=3.2，以及分别改变 C、D、ν、几何面积和 rpm 的比例测试。测试同时检查超范围数值保留并标记无效，不通过调参或选择 n 落在 2–4 内的点来强行得到结论。

默认共同覆盖范围并不自动等于适用 ORR 分析区间。应结合跨转速曲线、真实反应条件及模型适用性选择电位；KOH 文献参数不自动视为适用于其他电解液。

## 本次修复与提示改进

1. 批量应用时，即使读取文件的电解液文本没有改动，也同步到明确选择的目标文件。该缺陷已通过失败回归复现；修复后通过。
2. 展开显示实际参与拟合的文件、rpm、面积、pH、温度、电解液、坐标和扫描方向，便于逐项核对。
3. 分析区间默认展开，说明共同覆盖范围与 ORR 分析区间的区别；物性输入增加单位换算帮助。
4. 结果显示该次实际使用的 C／D／ν、区间与电位坐标；导出的 K–L 参数增加 `axis` 和 `units` 字段，原有项目 schema 不变。
5. 汇总模型检查未通过的点数和原因，明确超范围比例的解释限制。
6. 新计算失败时清除上一轮 K–L 结果及其图片/表格导出，避免误读旧结果。

科学公式未调整，未强行裁剪 n 或修改物性使结果回到 2–4。当前仍缺少用户这批实际参数和结果，不能将上述配置问题认定为此次异常的确定原因。

验证结果：独立合成包 86 项完整测试通过，真实浏览器参数核对、区间提示、单位导出和失败重算清理流程通过，页面脚本错误为 0。

## 复现本次异常仍需的信息

- 异常 n、对应电位及 status。
- 实际所选文件、rpm、面积、扫描方向及背景。
- 实际电解液、温度、氧饱和条件，以及 C／D／ν 数值和单位。
- 分析起止电位及原始／RHE 坐标。

可用软件导出的 `kl_parameters.json`、`kl_results.csv` 和全部参数 JSON，或保存的 `.orrproj` 复现。测试与浏览器验证结果记录于 `docs/VALIDATION.md`。
