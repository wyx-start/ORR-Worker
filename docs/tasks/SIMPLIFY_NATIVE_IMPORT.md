# 桌面导入页：默认直接绘图，按需修改条件

日期：2026-10-28；基于 M7 原生候选版 1.7.0-dev。用户要求进一步减少导入页填写和操作步骤，直接实施。

## 操作流程

默认路径缩为“拖入文件 → 核对用途、转速、背景与条件摘要 → 生成极化曲线”。不要求展开条件表，不添加必填确认框。新文件使用已有的 pH 13、SCE、25 °C、5 mm RDE、N=0.369 默认；这些是软件默认，实际实验不同应主动修改。

首页显示实际已应用／候选条件摘要，识别不同值和未知值。表格默认只展示文件、用途、转速、背景；样品名、分组、点数可通过“显示全部列”展开。空白转速仍可手改，不阻止单纯绘图；K–L 继续按原校验要求填写。

“修改本批常用设置”默认收起，包含范围、pH、参比预设和批量背景。修改直接加入统一草稿，仅覆盖主动修改字段。范围默认为全部样品，界面显示目标数量，提示不直接改背景独立记录；当前组、自选均可用。单击“应用并生成极化曲线”通过原有后台任务应用并计算，无须再去分析页点一次计算。

“逐文件／高级设置”保留完整编辑能力，默认收起。分析页的修改条件入口会自动展开它。逐文件扫描、B 规则、人工段、通道、符号、iR、面积、N、自定义参比、背景独立记录和兼容模式仍在原位置。补全转速、移除文件放入“更多”；有草稿才显示单独应用、放弃和草稿详情。

## 数据规则

- 不新增实验默认或项目字段；旧项目不同条件、空值、人工值不补成统一默认。
- 参比预设不改温度和电位换算方式；非理论 RHE 范围用高级设置调整。
- 修改采用持久化 records、统一补丁和来源记录。背景跟随、独立缓存、共享冲突规则及科学公式保持既有实现。
- 快速背景明确选择才修改；初始“保持各文件现有背景”不确认或覆盖已有绑定。双通道背景配对盘／环；非法通道整次拒绝。
- 错误 pH 保留在原编辑域。修正为已应用值也必须移除该域先前的接受修改，避免旧草稿在修正后复活。
- 读取、展开、切换来源／范围只改变显示；不会自动把首个样品条件复制到其他文件。
- 直接绘图使用明确范围，复用后台快照、取消和结果失效保护；原始文件与项目写入规则保持不变。
