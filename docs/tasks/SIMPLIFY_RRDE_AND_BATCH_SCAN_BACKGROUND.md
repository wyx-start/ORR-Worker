## 3. RRDE 收集效率 N 默认 0.369

### 3.1 新文件与普通操作

- 新导入的 RRDE 记录使用 N=0.369，编辑器直接显示该值，允许修改。
- 输入按 0～1 的小数表示；0.369 不转换为 36.9 或 369。
- 来源记录为“软件默认 0.369（可修改）”，不标成文件测得或实际标定。
- 用简短说明“初始值 0.369，可按实际校准值修改”，替换现有“N 不设通用校准值”的文案；不新增确认弹窗或额外必点操作。
- 不根据 5 mm 盘面积推算 N；不因使用默认 N 自动勾选环检测确认。

### 3.2 旧项目与人工值

- 已有非空 N 一律保留，例如 0.37、0.4 或用户自定义值；不在升级、载入项目或切换页面时覆盖。
- 旧项目明确保存空 N 时，载入本身仍保留空值。进入 RRDE 编辑时以 0.369 提供待应用初始值，明确软件默认来源，通过统一“应用设置／应用并计算”才写入记录。
- 这一初始值不会因页面渲染、选择读取来源或更换目标范围而自动提交。已有用户草稿优先，不能被默认值重新播种覆盖。
- 非法 N 继续报具体原因，不用 0.369 偷偷替代；校验仍为有限数值且 0 < N ≤ 1。
- 修改 N 后按现有规则清理旧 RRDE 结果与参数导出，保留完整来源。

- K–L 对已知实验条件不一致的检查保留，不能因移除电解液输入而放宽科学条件。
- 如旧记录因某项已知差异阻断计算，错误处应明确指出样品和字段，并提供只针对该项的按需纠正入口；不恢复整组常驻“补充实验记录”。修改仍进入统一草稿，只作用于明确选中的样品，不把 Ar/N₂ 背景改记为 O₂。
- 低电流过滤、无效电流符号、非物理选择性等状态保留，不截断异常结果、不改用绝对值。
- “当前实验条件”摘要、背景条件摘要与冲突修正入口不在本次删除范围。
- CSV、图片、参数与 .orrproj 分别导出继续可用；“保存分析项目”不属于被删除的预设保存区。

## 5. 扫描与背景批量设置及转速手动修正

### 5.1 入口与目标范围

保留“实验条件／扫描与背景”结构，在“扫描与背景”提供批量设置；逐文件检查作为同一区域的补充入口保留。

批量操作流程：

    选择范围与目标
      → 选择要统一的扫描／背景项
      → 加入本批草稿
      → 一次“应用设置”或“应用并计算／导出”

- 应用范围沿用“当前组／全部样品／自选”，默认当前组。
- 默认目标只包括样品与 RRDE，不把背景文件自动加入目标。
- 列出目标数量及文件名；选择范围或读取来源本身不复制设置。
- 扫描规则与背景设置分别可选。每项默认“保持各文件原设置”，只修改用户明确选定的字段。
- 批量扫描可以在自选范围明确包含背景；对背景只改其自己的扫描设置，不给背景批量绑定另一份背景。扫描与绑定混合操作的目标不合适时，明确列出原因，不静默跳过。
- 不增加第二个科学提交入口。“加入草稿”只表达批量意图，生效仍用现有统一入口。
- 旧“统一当前组扫描规则（清除其他文件人工选段）”勾选项由新范围控制取代，不同时保留两套相似批量入口。

### 5.2 批量扫描项目

支持：

- 扫描方向：保持／递减／递增。
- 自动选择方式：保持／A 最后完整循环支线／B 最后完整单向支线。

规则：

- A/B 必须逐文件从各自原始数据重新判断；不复制来源文件的行号、圈号或段编号。
- 明确选择自动 A/B 时，显示将清除目标文件人工选段的范围与数量，再随本次统一应用执行。仅选择目标或读取来源不清除人工段。
- 仅改方向而保留人工段时，不默默替换已选段；如实际人工段与新方向不相容，明确列出文件，要求选择自动规则、调整目标或逐文件修正。
- 自动找不到完整支线不冒充结构非法：允许保留合法记录，标明原因，并保留人工选择入口。实际绘图／处理按现有逐文件失败规则继续处理其他可用文件。
- 第一阶段不支持把某文件的“第 N 段”批量照搬到其他文件；人工选段仍逐文件核对。

### 5.3 批量背景项目

建议采用以下明确操作，默认“保持原设置”：

| 选择 | 对目标文件的作用 |
|---|---|
| 保持原设置 | 不生成绑定补丁。 |
| 统一盘背景（环保持） | 指定盘背景；环绑定原样保留。盘环文件如需解除原配对关系，以明确的分别指定模式表达，预览列出变化。 |
| 盘环配对背景 | 同一双通道背景盘扣盘、环扣环；目标与背景都须有合法的盘／环映射。 |
| 分别指定盘／环背景 | 分别选择盘、环背景，允许某通道“保持”或明确“不扣除”。 |
| 不扣背景 | 明确清空所选文件的盘／环绑定，保留背景文件及其独立条件记录。 |

- 引用只允许存在、角色为背景且不为目标自身的文件；预检查自身引用、循环、通道不合法及不兼容目标。
- 配对操作遇单通道文件时不偷偷降级或交换通道。列出不兼容文件，整次批量补丁不暂存；用户可调整所选范围或操作。
- 每个背景的通道映射、符号、扫描段仍属于该背景，不能从某个样品复制过去。
- 绑定、换绑、解除关联后重算背景有效条件；不同转速可共用背景，已知 pH／参比／温度等冲突继续按字段提示。
- 不自动改变背景 follow／independent／legacy_ph 策略，不改其独立条件缓存；新背景的默认跟随由既有核心处理。
- 不批量复制 N、面积、转速、iR 补偿、环固定电位或检测确认等未选择参数。

### 5.4 草稿、预览和原子性

- 以 get_draft_view 的 records 构建科学补丁；已暂存／拒绝输入通过 get_edit_configs 等编辑接口恢复，绝不修改有效投影。
- 先为全部目标构建和检查，再一次暂存。不允许逐文件成功一部分、失败一部分。
- 结构／绑定不合法则保留本次输入、列明文件原因，不改变既有记录或覆盖其他编辑域。
- 来源缺项、共享背景冲突与自动扫描不可用状态按既有规则保存和显示；计算／导出仍进行实际任务依赖检查。
- 修改摘要包括字段、目标、人工段清除情况、原背景和新背景，提供统一放弃草稿能力。
- 应用前已应用值保持不变；成功后递增修订，清理受影响的旧结果／导出。
- 批量设置与逐文件编辑发生同字段矛盾时明确提示，不用“最后编辑者覆盖”或清空其他域来解决。
- 跨页面、切换范围、候选失败、切换背景模式时，不丢失未应用输入；隐藏区块不再向草稿持续写旧值。

### 5.5 未识别转速的人工填写与修改

- 在“核对识别结果”的“转速/rpm”列直接逐文件填写或修改，不要求先成功识别，也不要求修改原文件名。未识别、识别冲突、推测值、明确识别值均可编辑，并显示转速来源及识别说明。
- 没有可靠识别结果时保持空白并提示“未识别，可手动填写”，不能默认猜成 0、1600 或其他文件的转速。识别冲突时保留具体候选与原因，允许用户自行填写实际值。
- 人工修改进入现有统一草稿，通过“应用设置／应用并计算”生效；页面刷新、切换范围或重新显示识别信息不自动提交，也不覆盖人工输入。实际改值后来源标为“人工填写”，保留原文件名识别依据用于核查；仅确认未改动的识别值不改写其来源。
- 转速接受有限、非负数，单位为 rpm；0 表示明确的静止测试，不能代表未知转速。负数、非数值或无穷值须说明原因，并保留输入供修正。
- 允许手动清空转速；清空后保持空白，不因重新渲染而自动识别填回。现有“根据文件名补全空白转速”作为显式操作保留，可重新尝试空白项，但不能覆盖任何非空人工值。
- 缺少转速不一概阻止普通绘图或 RRDE 分析；K–L 等确实依赖转速的计算继续按任务校验，明确列出缺失或不合要求的文件。K–L 使用正转速且满足既有有效转速数量要求，重复转速不能冒充不同转速。
- 这是逐文件元数据修正，不把一个转速自动复制到整组；批量扫描／背景操作不改未选定的转速，不把样品转速反向写入背景。
- 应用后按既有依赖规则使受影响结果过期。项目保存／恢复和参数导出保留实际转速、人工来源及识别依据；处理数据中的转速与已应用值一致。

## 7. 验收清单

### RRDE 与界面精简

- 新 RRDE 导入后 N 显示 0.369，来源为软件默认；用户可改为 0.4 并按实际值计算。
- 旧项目 N=0.37 保留；空值只在编辑草稿中提供默认，载入不改保存值；非法值不自动修复。
- 用独立已知答案比较 N=0.369 和人工 N 的 RRDE 结果，确认只改变预期参数且结果过期处理正确。
- 所有相关页面实际不再出现四个区块及其控件；不是折叠隐藏，也不靠保留旧文案满足测试。
- 删除区块后修改 pH／参比／N，不会把未显示的 electrolyte、已有 presets 或参数来源清空。
- 新项目用 1e-9 A 阈值；旧项目有效自定义阈值继续生效并进入参数导出，异常点状态一致。
- 移除重复 RRDE 核对表后，关键错误与不完整记录仍可定位和修正。

### 批量扫描／背景

- 用同组约 10 份合成文件一次统一方向及 A/B，实际扫描段来自各文件；其他组与未选择文件不变。
- 选择范围、来源或展开页面不产生隐式修改；默认“保持”不清空任何绑定或人工段。
- 有人工段时明确显示影响，批量自动选择后只清除明确选定的目标；不能跨文件复制段号。
- 同一盘背景的批量绑定、替换、解除正确；配对背景仍盘扣盘、环扣环，不混用通道。
- 盘环／单通道混选、不合法映射、自身引用等失败无部分暂存；科学缺项和自动扫描失败单独记录，其他可用数据继续处理。
- 共享背景不同转速可用；已知条件冲突不能被批量操作绕过，也不反向修改样品条件。
- 批量与逐文件跨域矛盾被保留，修复或放弃后结果一致；背景模式切换不丢无关编辑。
