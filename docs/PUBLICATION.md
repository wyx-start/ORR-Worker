# GitHub 公开版本说明

仓库：<https://github.com/wyx-start/ORR-Worker>。发布版本：1.3.1。

公开包包含源码、测试、使用及开发文档和四份合成示例。没有上传用户的原始 TXT、实际分析项目、本机常用条件、运行日志或浏览器验证下载。原开发环境中的真实数据保持不变。

`examples/` 的公开数据全部由 `tools/generate_demo_data.py` 生成，没有读取实测电流。文件名保留历史测试命名以兼容回归用例，不能解释为实际催化剂、电解液 pH 或产物选择性。开发文档中的真实样例验证是历史记录，原文件没有随仓库公开。

公开包在独立目录中运行完整测试：66 项通过，耗时 13.168 秒。该结果包含合成示例的解析、分段、背景、界面、pH/背景诊断与项目恢复，以及具有独立正确答案的 K–L/RRDE 数值测试。

Windows 双击脚本优先使用 `.venv\Scripts\pythonw.exe`，否则使用 `pyw -3.13`。本机已验证 Python Launcher 能解析到 Python 3.13.7；新机器先按 README 创建虚拟环境并安装依赖。浏览器测试改为可选 Playwright 模块解析，日常运行不需要 Node.js 或 Playwright。

本次发布采用在已有主分支历史上增加提交的方式，不覆盖仓库历史。用户选择的项目名、软件版本与方法说明均保留；不自动授予或更改开源许可证。
