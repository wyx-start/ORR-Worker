## 范围与结果

本次按已确认的环电流比较/背景配对任务实现；保留 K–L 改进与原始实验文件。核心模型公式未调整。102 项完整测试通过，真实浏览器下载和恢复验证通过；当前审查范围内无未解决的交付阻断项。

## 审查中发现并修复

1. 原处理先校验盘并扣盘背景，环图可能被无关盘条件阻断。新增通道范围与背景参与开关，默认全通道兼容旧调用；环图只读取所需依赖，iR 仍使用原始盘电流。
2. `None` 作为背景下拉框选项时，解除后可能恢复非空默认。用具体空哨兵在 UI 中选择，提交时再转 None；界面回归和真实浏览器均确认独立环背景可解除、配对可同时解除。
3. 原平滑仅生成盘绘图列。新增独立环列、单位与处理范围记录，缺口和原始数据保持；相关盘/环回归再次通过。
4. 下载触发重运行时截图可能捕获暂时灰显，测试等待完成再拍摄；最终截图已确认轴、单位、样品图例及差异文件/数值可读。

## 重点检查

- 配对提交使用一套校验函数；先验证样品和背景映射、身份和用途，再同时写两个关联。批量入口完成全部行验证后统一提交，不留半更新。
- 旧项目缺少新字段时用独立模式保留原绑定；不依据文件名或候选覆盖人工值。只有显式应用配对才替换两条关联。
- 环图无需 N 或面积，不将电流除以 N 或取绝对值；原始符号、参与背景及映射均可追溯。
- 比较忽略用户指定例外（rpm、固定环设定电位），未知只作提示；逐字段比较全部已知值，不以缺失绕过冲突。实际电位换算和 iR 必需依赖仍有效。
- 未扣背景开关不改配置；未参与背景/未覆盖背景明确为 NaN 与状态。CSV 的绘图值、单位、视图、原始及修正列不混淆。
- 环图导出与盘图区分，科学输入变化统一失效；仅图形选项变化不清除 K–L/RRDE 结果。冲突后不保留旧环图和下载。
- 新项目设置和映射保存恢复；参数包含处理范围及比较校验状态，不能把允许绘图写成所有实验条件已核对。

## 保留的边界

- 电解液名称只做无歧义文字规范化，不自动判断不同配方等价。
- 固定环电位不参与比较拦截是用户明确要求，记录仍保留；未记录项不被软件推定。
- 支持现有 CHI 文本与选段规则，不增加固定电位 i–t、响应时滞补偿、环面积归一化或 N 标定。
- 1.5.0 于 2026-10-19 按用户要求同步 GitHub，另做公开文件范围审查；实测数据、本机配置及验证下载排除，排查文档公开副本移除本机参数和实测结果。现有用户会话需保存项目并重启后载入新模块。
