# ORR Worker 1.6.0 审查记录

本轮按 `tasks/UI_SIMPLIFICATION_WORK_PLAN.md` 整理操作与导出。保留五页导航，合并科学设置提交边界；新增 Origin 绘图宽表，未修改 ORR、K–L 或 RRDE 公式。

## 实现与复核范围

- `settings_draft.py`：独立草稿、来源域冲突、候选深拷贝、修订和结构校验；提交同时覆盖文件配置和全局电位轴。
- `ui_shared.py`、`condition_ui.py`、`settings_editor.py`：统一应用、跨页草稿、明确目标、预设与背景 pH、拒绝输入保留及修复。
- `app_pages/`：先选择任务文件，显示用途相关缺项；K–L／RRDE 显式计算、输入签名和旧结果清理。
- `origin_export.py`：独立网格 XY／多 Y 列组，保留顺序、点数、缺口、符号和异常值，不重新插值。
- `download_ui.py`：原生按钮先完成当前任务，再用 Streamlit v2 组件把不可变字节交给浏览器；收到交接事件后重绘，恢复其他下载入口。

## 审查中发现并修复

1. **一处拒绝暂存的值可能被其他域掩盖。** 改为按编辑域记录拒绝值与错误；无关域成功不解除阻断，冲突修复后才能应用。
2. **导入会清掉旧草稿。** 有未应用修改时先保留并提示处理；项目恢复仍是明确替换工作区。
3. **背景 pH 预览与候选处理不同步。** 有效候选在副本上解析共享 pH；无效草稿仍可显示和修复，任务不使用宽松显示副本。
4. **新增文件后的侧栏控件修订滞后。** 导入完成后正常重跑，使第一次坐标选择生效。
5. **部分文件缺项导致绘图颜色索引错误。** 绘图只使用实际可用的选中输出，失败文件单独报告；K–L 仍不允许静默漏掉所选转速。
6. **普通条件暂存时主动重跑吞掉同次导出点击。** 移除多余重跑，各页在编辑器之后读取同一候选；最后输入可与按钮一次提交。
7. **v2 下载把 ShadowRoot 当作有 dataset 的元素。** 改在组件自身状态元素记录令牌；浏览器实际验证文件下载，不能只依赖 Python 测试。
8. **组合导出后未登记新绘图 CSV。** 返回的文件字节写入当前导出仓库，且成功提交后不把本次旧附件重新写入。
9. **恢复项目可能沿用旧分析控件值。** 引入只在恢复项目时变化的工作区身份，K–L 物性／区间／点数和 RRDE 阈值重新读取项目设置。
10. **原始视图中的“已是 RHE”文件列名与图不一致。** 按实际有效坐标标记绘图 CSV，保留用户选择的处理方式和原数值。
11. **下载后其他导出区暂时消失。** 文件交接后自动重绘，继续提供当前结果的 PNG、SVG、完整数据和参数。

## 科学与兼容边界

- 核心计算和背景 0／NaN 的既有数值语义保留，以状态区分未绑定、未参与和真实零背景。
- 合法但缺项或共享 pH 冲突的记录可应用／保存项目；实际需要这些条件的分析或导出预检查阻断。非法通道、无效值等不提交。
- 平滑只作用于显示副本；绘图 CSV 跟随实线，完整数据和科学计算保留未平滑值。
- 配对背景按逻辑通道盘扣盘、环扣环；旧独立背景、人工值和 schema=1 项目继续保留。
- 全局电位轴属于科学设置；颜色、图例、显示单位和平滑仅刷新对应图与导出。

最终测试数量、浏览器断言及结果见 `VALIDATION.md`。发布文件采用源码／文档／测试白名单和合成示例；本机实验数据、项目、预设及验证下载不上传。
