# ORR Worker 桌面版使用指南

本轮为 Windows 本机候选版。已在本机验证；尚未在全新、没有 Python 的 Windows 系统上验收。

## 启动与退出

解压完整目录，双击 **ORR Worker.exe**。保留旁边的 `_internal`、许可证和说明文件，不要只复制 exe。程序自带运行环境，启动时不执行安装命令，也不需要浏览器或本机服务。

同一程序目录再次启动会提示已有窗口。退出前保存 `.orrproj` 分析项目；窗口会区分未应用修改和未保存工作。任务中可取消，等待当前步骤结束。选择保存但保存失败时，窗口和输入会保留。

## 第一批文件

1. 在“导入与设置”拖入 TXT／CSV／DAT，或点击“导入文件”。按每批约 10 个文件验证。坏文件保留具体原因，其余文件继续；重复文件不重复导入。
2. 默认表格只显示文件、用途、转速、背景；双击可改用途、转速或背景。“显示全部列”可查看样品名、分组和点数。K–L 中同一电极的多转速文件放在同组；单纯绘图可以不填转速。
3. 核对首页条件摘要后，直接点 **生成极化曲线**。新文件默认 **pH 13、SCE／饱和 KCl／25 °C、直径 5 mm RDE、RRDE N=0.369**；不需要逐项重填。旧项目的空值、人工值和差异保留，摘要会显示“未记录／各文件不同”。
4. 需要改一批文件时，展开 **修改本批常用设置**，选择全部样品、当前组或表格选中，修改 pH、参比或选择配对背景。只改动主动修改的一项，背景条件仍按各自继承策略。修改进入草稿后可直接 **应用并生成极化曲线**，也可单独应用或放弃。
5. 更多参数在 **逐文件／高级设置**：先选读取来源，再核对“仅此文件／当前组／全部样品／表格选中”的范围。面积、N、温度、自定义参比、电位方式等仍可编辑；切换来源和范围本身不复制条件。快速 pH 留空表示保持；需要明确清空旧值时使用高级设置。
6. 人工选段在高级设置中的“逐文件扫描与背景”。A 为最后完整循环中的指定方向支线，B 为最后完整支线；默认递减。可人工选择不完整段，参数保留记录。逐文件页只修改当前文件。批量扫描／背景可先预览再暂存；全“保持”不清除之前的修改。选一个双通道配对背景会自动盘扣盘、环扣环；不同背景可分别指定。

## 电位与背景条件

理论 RHE 使用实际 pH、温度和参比电位。参比预设仅适用标明的温度；其他温度填写实测值，或选择“实测 RHE 总偏移”。实测偏移允许 0；“已是 RHE”不会再次平移。选择“原始”则保留原参比坐标。

新背景默认整组跟随对应样品的电位方法、pH、温度和参比；无需重复填写。共享背景关联的样品条件冲突时，会列明字段和来源，不用旧独立值凑出结果。不同转速可以共用背景。

实际背景条件不同，可在背景页“切到独立设置”。此操作只切模式，不复制数值；原独立缓存保留。“用当前有效条件建立独立记录”是另一个明确的复制动作，等待或冲突时不可用。旧项目的仅 pH 跟随规则继续保留。

## 绘图与分析

- **极化曲线**：选择盘／环、样品、单位和背景前后。颜色、图例、标题、坐标和显示平滑即时预览。平滑不进入 K–L／RRDE；缺口不补齐，不等间距和短段会注明跳过。
- **环电流比较**：允许转速、环设定电位不同；其他已知条件冲突会阻止。未知条件会提示，不能当作已核对一致。环电流保留符号，不除以 N。
- **K–L**：选择同组不同转速，核对物性方案、区间与点数并确认。程序给出的共同覆盖只是数据范围，不是自动认定的 ORR 适用区间。全部所选转速必须有效；不会跳过失败转速来凑拟合。支持电子数、两路径估算和逐电位拟合图。
- **RRDE**：保留各文件的 N；值不同时输入框显示不同／未知，主动填写才批量修改所选文件。检查环检测确认及异常点。旧低电流阈值沿用项目记录，没有重新增加阈值设置区。

超出模型范围的数值和原因会保留，不裁剪成“正常选择性”。K–L 两路径比例与 RRDE 两产物模型需要各自假设，不能一概等同于实测法拉第效率。

后台任务期间可以修改条件；返回结果若与当前输入不符，会丢弃并提示重新计算。取消或失败不会保存旧分析结果。

## 导出到 Origin

优先点击分析页的 **保存绘图 CSV**。每个样品分别占独立 X／Y 列组，保留自己的电位、点数和空缺；平滑、单位和背景显示与当前图一致。RRDE 含独立电位／产率／电子数／模型比例列；K–L 另有各电位的独立拟合 XY／拟合值表。

完整数据 CSV 另含原电流、背景、处理记录和异常原因，未平滑电流列保留。PNG、SVG、参数 JSON 可分别保存；“更多导出”选择具体文件。

“导出与项目”的配置参数 JSON 记录当前配置，不覆盖分析页的实际处理参数。结果 ZIP 收集当前已生成文件；`.orrproj` 保存原始字节和设置，用于继续工作。项目恢复后需重新计算，不把旧下载当作新结果。保存项目也保留有效但尚未计算的 K–L 输入。

## 常见问题

“有效条件视图不能直接修改”属于开发接口保护；桌面控件已使用持久化记录构建补丁。遇到拒绝修改，先看草稿详情并修正原编辑域，或明确放弃草稿。

背景显示冲突时，先检查关联样品的 pH、参比和温度是否一致。仅切独立模式不会自动把样品条件写入背景；请按实际实验填写。

文件被占用或只读时，关闭占用程序或另选保存位置；原文件不会被半成品替换。后台日志位于 `%LOCALAPPDATA%/ORR Worker/desktop/jobs.log`，入口错误见同目录 `last_error.log`。
