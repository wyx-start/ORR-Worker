## 1.5.0 — 2026-10-18 实现，2026-10-19 更新 GitHub

- 新增盘/环电流切换及跨样品环图，默认 μA，可选 mA、处理后/未扣背景；环图单独导出 PNG/SVG/CSV/参数，并保存设置到项目。
- 新 RRDE 提供盘环配对背景，在批量与逐文件入口同时建立盘/环关联，按逻辑通道分别扣除；高级模式与旧项目继续保留独立绑定。
- 环图仅处理所需通道与背景，不被无关盘背景阻断；启用 iR 时仍检查原始盘电流。未参与背景导出为缺失值及状态，不冒充零背景。
- 比较允许转速和环设定电位不同、记录缺失；其他已知条件冲突明确阻止，导出核对结果。环图不要求 N 或盘面积。
- 扩展独立环电流绘图平滑，保留缺口和原始数据；图形设置不改变 K–L/RRDE 计算。
- 修复背景下拉框选“不扣除”可能恢复旧值的问题；空选择在界面与提交时明确区分。
- 102 项完整回归和真实浏览器环图/背景/导出/项目恢复流程通过，详见 VALIDATION。

## 1.4.0 — 2026-10-15

- 界面、浏览器标题、启动提示和项目文档统一命名为 ORR Worker；默认项目文件名为 `ORR_Worker_analysis.orrproj`。

- 核心处理、参数导出与项目保存恢复使用同一解析规则；旧项目保留原 pH，schema 仍为 1。
- 仅联动 pH，保留现有参比、温度、气氛、背景插值和科学计算规则。
- 公开合成发布包 83 项测试通过；审核与浏览器证据见版本审查及验证文档。
