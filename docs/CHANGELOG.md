# 版本记录

## 1.3.1 — 2026-10-15

- 准备 GitHub 发布包与完整安装 README；公开示例使用合成数据，排除本机真实数据和配置。
- Windows 双击脚本优先使用项目 `.venv`，否则调用 `pyw -3.13`，移除用户专属解释器路径；浏览器依赖改为可选模块解析。
- 明确提示实验条件修改尚未应用，防止将输入框草稿误认为计算参数。
- 有未应用修改时，保存项目/本机常用条件会提示先应用，避免保存旧空值。
- 缺少背景 pH/参比等条件时，摘要和处理错误明确指出背景文件名。
- 增加主动“将关联背景加入应用范围”，仅由用户确认同条件后共同应用，不自动复制参数。
- 支持单独读取并编辑背景条件，不要求背景填写盘面积或 N。
- 完整测试 66 项通过；新增真实浏览器 pH/背景回归验证。

## 1.3.0 — 2026-10-15

- 按当前绘图、K–L、RRDE 用途显示实验条件，必填标记 `*`，汇总缺失项并提供原始电位预览入口。
- 三种 RHE 方式条件显隐；内置参比方案自动提供数值与来源，自定义才显示详细输入，实测 0 V 有效。
- 新文件默认直径 5 mm RDE、面积 π/16 cm²；支持改直径或直接输入面积，内部保留精度，保护旧项目面积。
- 高级扫描、通道、iR、拟合区间及阈值折叠；单通道隐藏环信息，人工选段时展示完整 CV 和段列表。
- K–L 参数改为方案选择，适用文献方案一次提供 C/D/ν；不自动推定 Na 电解液适用 KOH 参数。
- 增加本机常用条件存取，保留项目预设；主动套用、默认补空白和软件默认，防止混合不兼容参比，不继承文件身份或确认标志。
- 批量条件默认限同组；隐藏字段不清空，参数来源随 JSON 和项目保存，schema 保持 1。
- 无效面积不阻塞电流图或 RRDE 比值，电流密度与 K–L 继续严格要求有效面积；旧无效值可以在界面修复。
- 导出页下载不触发计算重运行，减少下载中断。未改动科学计算公式及平滑用途。
- 63 项测试通过，并完成隔离本机服务上的真实浏览器验证；同步使用指南、项目说明、任务与验证记录。

## 1.2.0 — 2026-10-15

- 根据已确认任务文档增加文件名转速识别，支持“1600转”、rpm 前后缀及“转速=1600”等写法。
- 明确标记优先，兼容旧式末尾整数推测；相同候选去重，冲突/小数/负数/不支持单位留空说明。
- 核对表增加只读转速来源，展开可查匹配片段、候选与原因。
- 增加“根据文件名补全空白转速”，保留非空人工值、零转速及分组；有数值变动时旧结果和导出失效。
- 手动改值记录来源；确认、重复导入及项目恢复不重新覆盖人工值。
- 默认分组移除转速片段，保留其他实验条件。
- 项目与参数保存识别依据；旧项目保留原值并标记来源未记录，schema 仍为 1。
- 49 项测试通过；实际浏览器上传、旧项目、补空白和保存恢复验证通过。

## 1.1.0 — 2026-10-14

- 增加极化曲线仅绘图的 Savitzky–Golay 平滑，默认关闭，固定二阶多项式。
- 提供弱/中/强 11/21/51 点与自定义奇数窗口，同图统一参数并显示实际电位跨度。
- 默认叠加浅色未平滑参考线，可隐藏；PNG/SVG 标明仅绘图平滑。
- 分连续有效段处理，保留缺口；短段、不均匀、重复或非单调电位段保留原值并报告，不自动缩窗、补点或重采样。
- 极化 CSV 保留原有列，新增 smoothed_plot_only 列与逐点状态；计算列不变。
- 平滑配置与报告写入参数/项目；旧项目默认关闭，schema 保持 1。
- 修改平滑不清空或改变 K–L/RRDE 结果，只更新极化输出。
- 增加 SciPy 1.17.1 依赖、平滑数值与界面测试，并更新使用和维护文档。
