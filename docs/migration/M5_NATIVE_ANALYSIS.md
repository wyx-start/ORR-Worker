| 失败保护 | 计算开始清除该任务旧结果与下载；非法候选、缺转速、未确认或条件冲突均不输出旧文件。预览不提交科学设置；CSV 导出可明确合并应用与计算 |

## 共享实现

`application.curves` 管理原生图形数据与 Origin CSV；`application.results` 构建各分析图和完整导出；模型继续调用 M2 共享服务和原 `orr_core`，未更换计算公式或项目格式。Qt 层保留控件与选择，不在记录中保存画布对象。

分析页的“修改实验条件／扫描与背景”直接把当前选中文件作为明确编辑范围，不自动复制条件。背景继承和草稿规则继续由 M4 服务负责。
