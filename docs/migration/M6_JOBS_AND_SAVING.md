# M6 后台任务、保存与退出

日期：2026-10-27。

## 行为

导入与项目读取、分析、共同覆盖预览、图形文件生成、结果包和项目保存均有受控后台入口。单窗口同时运行一项任务，显示进度并允许取消；实验条件仍可编辑。任务期间暂时隐藏 Matplotlib 画布，避免主线程绘图与后台导出同时操作 Matplotlib；窗口、文字控件、选择和取消仍能响应。

任务输入序列化为本进程创建的不可变字节快照，工作线程只使用独立工作区，不读写 Qt 控件或实时记录。这里的 pickle 仅用于可信的进程内快照，不读取用户 pickle；项目仍用原 `.orrproj` ZIP 格式。

返回时核对配置修订、项目／草稿／结果状态、任务输入和编辑时序。输入改变、未提交文本改变或取消后，返回结果直接丢弃；不会回写新设置或把旧结果重新放回下载列表。任务开始清除该分析的旧下载，失败／取消不以旧结果替代。

保存采用两阶段方式：后台在目标目录生成并同步临时文件；主线程核对任务仍有效，再一次替换正式文件并接收工作区。写入、同步、替换失败时，原文件和实时草稿保留。晚到的取消即使发生在临时文件完成后，也会阻止正式替换。

## 项目与关闭

- 持续区分未应用草稿、未保存项目和需重新生成的分析结果；窗口标题 `*` 与底部状态对应当前工作。
- 保存项目同时收集尚未计算的有效 K–L 参数与 RRDE 选择，写入已有 settings 字段；不增加项目 schema，不默认填补旧条件。非法原始参数文本会阻止保存并保留输入。
- 正常关闭和替换项目提供保存、放弃、取消；保存失败窗口保持打开。任务中关闭先请求取消并等待线程结束，随后处理未保存工作，不强行终止工作线程。
- 同一安装目录使用 Qt 文件锁限制重复启动；进程正常退出释放锁。不同程序目录／版本不互相结束进程，旧浏览器会话不受影响。
- 日志在 `%LOCALAPPDATA%/ORR Worker/desktop/`，不写到程序资源目录；后台错误写入 jobs.log，入口错误写入 last_error.log。

为回归工具保留直接调用的同步辅助方法；生产按钮、拖放、文件选择与导出使用后台入口，业务计算共用相同应用服务。同步保存辅助也使用快照与原子替换，不先修改实时配置再尝试写文件。
