# ORR Worker

**源码版本：1.7.0-dev** · 稳定版：1.6.0 · Windows 本地运行 · Streamlit 前端 · CHI760F 文本数据

当前开发工作区为 **1.7.0-dev**：已集成背景整组条件继承与独立记录保护，支持批量扫描／背景设置、空转速人工填写及 RRDE 默认 N=0.369；四个重复或低频区块已移除。实施与验证见 [本轮记录](docs/VALIDATION_1.7.0_DEV.md)。开发版保存的 schema=2 项目需新版本读取，1.6.0 会明确拒绝打开。

ORR Worker 用于批量处理氧还原反应数据：从 CV 选择单向扫描段、绘制极化曲线，并进行多转速 K–L 和 RRDE 分析。安装完成后可双击启动，不需要编写 Python。按每批 10 个文件验证，数据在本机处理。

仓库地址：[wyx-start/ORR-Worker](https://github.com/wyx-start/ORR-Worker)。

桌面改写已按阶段启动：[进度与验收](docs/migration/STAGE_LOG.md)。M1 浏览器版 exe 已通过本机冻结程序测试，[构建与使用说明](docs/migration/M1_BROWSER_EXE.md)；原生桌面版继续开发。用户当前无干净测试机，跨机器无 Python 验收尚未完成。

## 功能

| 功能 | 支持内容 |
|---|---|
| 批量导入 | CHI 文本 TXT/CSV/DAT，核对样品、转速、用途和分组；异常文件单独报告 |
| 扫描提取 | 默认最后完整循环的递减支线；支持 B 模式、递增方向和人工选段；可按组、全部样品或自选批量设置 |
| 转速识别 | `1600转`、`1600rpm`、`RPM1600`、`转速=1600`；冲突不盲选；未识别值可直接手填，已识别值可修改，人工值优先 |
| 电位与背景 | 理论 RHE、实测总偏移、已是 RHE、原始坐标；盘环独立背景、不外推；新背景的电位换算、pH、温度与参比默认整组跟随样品 |
| 曲线 | 盘/环电流切换、跨样品环电流比较、μA/mA、处理后/未扣背景、颜色和坐标设置、仅绘图平滑 |
| 盘环配对背景 | 选一个双通道背景自动盘扣盘、环扣环；保留分别指定与旧项目绑定 |
| K–L | 表观电子数、拟合与逐点结果、2e/4e 两路径模型估算 |
| RRDE | 过氧化物产率、电子数和两产物模型下的 4e 比例；新文件 N 默认 0.369，可改为实际标定值，旧值保留 |
| 条件简化 | 共享草稿、统一应用、明确批量范围；应用并计算／导出／保存；按用途显示必填项 |
| 导出 | Origin 绘图 CSV 优先、独立 XY 列组；完整 CSV、PNG 300 dpi、SVG、参数 JSON、ZIP、`.orrproj` |

## 下载与安装

验证环境：Windows、Python **3.13.7**、Streamlit **1.61.0**。其余依赖固定在 [requirements.txt](requirements.txt)；尚未验证其他 Python 主次版本。

1. 安装 Python 3.13，并包含 Python Launcher（`py` / `pyw`）。
2. 从仓库页面点击 **Code → Download ZIP**，解压；也可以使用 Git：

   ```powershell
   git clone https://github.com/wyx-start/ORR-Worker.git
   cd ORR-Worker
   ```

3. 在项目文件夹打开 PowerShell，完成一次环境安装：

   ```powershell
   py -3.13 -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   ```

不需要激活虚拟环境，也不需要修改 PowerShell 执行策略。项目不包含 Python 安装程序或免安装 EXE。

## 启动与关闭

双击 **启动 ORR.cmd**，浏览器会自动打开。脚本优先使用项目 `.venv`，未创建时使用 Python Launcher 的 3.13 环境。再次启动会复用已有服务。

双击 **停止 ORR.cmd** 关闭后台服务。关闭浏览器本身不会关闭服务，也不会自动保存项目。

也可在 PowerShell 运行：

```powershell
.\.venv\Scripts\python.exe launch.py
```

服务仅监听 `127.0.0.1`，通常打开 `http://127.0.0.1:8765/orr-workbench/`；端口被占用时会从 8765–8794 选择其他端口。以自动打开的地址或 `.runtime/server.json` 为准。启动日志位于 `.runtime/server.log`。

## 第一次处理数据

1. 在「导入与设置」拖入 TXT，点击导入；也可点击“载入四份示例”体验流程。
2. 核对样品名称、分组、转速、文件用途和背景。修改先进入草稿；支持文件名中的 `1600转`、`1600rpm`、`RPM1600`、`转速=1600`，识别来源仍须核对。
3. 查看“当前实验条件”，需要时展开“修改实验条件”。带 `*` 的项目是当前操作必填；理论 RHE 默认 pH 13、25 °C 和 SCE（饱和 KCl），可按实际实验修改，也可选择实测总偏移或已是 RHE。只预览原始电位 mA 曲线无需额外实验数值。
4. 在「扫描与背景」核对方向与背景；A/B、人工选段、通道和 iR 在高级区。完成本批修改后点击一次「应用设置」；来源文件与应用目标可分别核对。
5. 在分析页先选文件。极化图即时预览，K–L／RRDE 点击计算；有草稿时可直接「应用并计算」或「应用并导出绘图 CSV」。平滑只改绘图，不进入科学分析。
6. 优先下载绘图 CSV 导入 Origin。PNG 直接下载；SVG、完整数据、参数和 ZIP 在「更多导出」。在「导出与项目」保存 `.orrproj`；有草稿时可「应用并保存项目」。下次恢复后重新计算。

原始实验文件不会修改。关闭浏览器不会自动保存会话，也不会自动关闭服务。

### 填了 pH 仍提示缺少？

输入框是草稿，填写后点击统一的 **应用设置**，或直接使用 **应用并计算／导出**。草稿可跨页保留；状态区区分已应用与待修改值。校验失败保留草稿，不下载旧结果。

新背景默认整组跟随关联样品的换算方式、pH、温度及参比等电位条件。无需重复填写；关联样品已知条件不一致时会列出具体字段和值。背景自己的独立记录保留，可在“背景实验条件”中明确切换独立设置。旧项目保留原策略，旧版 pH 面板仍可使用。

“扫描与背景”可先选当前组、全部样品或自选，再选扫描规则与背景操作，预览后“加入本批草稿”，最后统一应用。自动规则逐文件选段，不复制段号；转速、N 和未选参数不会被批量覆盖。普通条件编辑不再显示常用条件保存区，已有项目预设和本机预设文件保留。

## 导出到 Origin（1.6.0）

“下载绘图 CSV”输出数值宽表，每个样品使用独立的电位 X 和电流 Y 列，列名带样品、唯一标识、坐标和单位。各曲线保留自己的电位网格与点数，短列末尾留空，内部缺口保留，不为导出重新插值。导入 Origin 后按重复的 X／Y 列组指定即可。

绘图 CSV 与当前实线一致，包括盘／环、单位、背景显示及显示平滑。平滑列名包含 `smoothed_plot_only`。需要核查原始、背景和未平滑处理值时下载“完整数据 CSV”；K–L／RRDE 始终使用未平滑电流。

K–L 提供共用电位的结果表，并在更多导出中提供各分析电位独立的 X／实测 Y／拟合 Y 列组；RRDE 为每个样品保留自己的电位及产率、电子数、模型比例列。异常数值与完整表中的状态继续保留。

科学设置尚未应用时，旧结果图片和附件暂停下载。组合导出先校验并应用新设置，生成成功后才把文件交给浏览器；失败会显示原因。缺项或共享背景 pH 冲突可以保存在项目中，实际依赖这些条件的分析仍需修复后才能运行。

## 方法与限制

- 从 CV 截取单向支线，输出记录明确保留 CV 来源。这不会消除之前的扫描历史，也不等同于独立进行的 LSV 实验。
- 默认 A：最后完整循环中的电位递减支线；B：最后完整的指定方向支线。默认容许一个采样步的端点差（数值公差 1.01 步），不会补造端点。缺少程序上下限时必须人工选段。
- 背景各自识别扫描段后，按同方向和同电位坐标线性插值。仅在覆盖范围扣除，不外推。扫描范围、扫描速率和补偿记录不同都会提示。
- 盘、环用带符号电流分别减背景，随后检查反应方向；不通过取绝对值掩盖错误。RRDE 公式使用实际电流 A，不混用分别归一化后的盘环电流密度。
- RRDE：`H2O2%=200*(R/N)/(D+R/N)`，`n=4*D/(D+R/N)`，其中 D、R 为校正后的正反应幅值。`100-H2O2%` 仅为两产物模型下的四电子比例，不是法拉第效率。收集效率 N 默认 0.369，可按实际标定修改；环材质、电位及是否能定量检测应核对。
- K–L 使用 j（A/cm²），`omega=2*pi*rpm/60`。`n=1/[slope*0.62*F*D^(2/3)*nu^(-1/6)*C]`；物性输入使用 cm 制。两转速不报告有意义的 R² 和标准误；重复转速需选择一条。额外电子数标准误仅传播回归斜率误差，不包含物性和测量不确定度。
- K–L `2e%=50*(4-n)` 与 `4e%=50*(n-2)` 是平行两路径假设下的估算，不能视作无条件准确的产物比例。没有做选择性或电子数裁剪。
- pH 修正为 `2.303RT/F*pH`；理论参比电位也必须适用于所选温度。实测 RHE 总偏移直接加一次，已经是 RHE 的数据不再换算。文献参比预设均仅供 25°C 使用。
- 默认不追加 iR。明确启用时使用**未经背景扣除的有符号总盘电流**与剩余未补偿电阻，`E_corrected=E_raw-I_anodic_positive*R_remaining`。不会从 Comp R、UC R 字段推定已执行的补偿状态。
- 当前直接支持带 `Potential/V` 表头的辰华文本及 A/mA/µA/nA 单位，不解析辰华原始二进制。

## 环电流比较与盘环背景配对（1.5.0）

在“极化曲线”选择“绘制通道 → 环电流”，再按组或选“全部”自由勾选不同样品。横轴是盘扫描电位；环电流默认 μA，可切 mA，保留原始符号，不除以 N。默认按已应用环背景处理，也可切“未扣背景”，不会改动选择性分析的背景绑定。环图无需 N 或盘面积。

转速和环设定电位允许不同；其他已知条件冲突时列出文件和值并阻止叠加。缺失比较记录只提示“未完整核对”，允许绘图；理论 RHE、iR 及参与扣除的背景所必需输入仍须有效。PNG/SVG/CSV/参数使用独立的 `ring_current*` 文件名，不覆盖盘图。

新 RRDE 默认“盘环配对背景”：在导入表选“盘背景”，或在“扫描与背景”选“盘环配对背景文件”，应用后同时绑定盘和环。扣除按各文件实际逻辑通道映射进行；单通道背景请用“分别指定背景”。旧项目自动保留独立模式和既有绑定，主动选择配对后才替换。

详细规则与验收见 [任务文档](docs/tasks/RING_CURRENT_COMPARISON_AND_PAIRED_BACKGROUND.md) 和 [使用指南](docs/USER_GUIDE.md)，版本同步情况见 [发布记录](docs/PUBLICATION.md)。

## 背景条件整组跟随（1.7.0 开发版）

- 新背景跟随样品的换算方式、pH、温度、参比电极／内充液／参比电位及实测 RHE 总偏移。
- 共用背景采用一套一致有效条件；冲突按字段提示，不任选样品，不回退旧独立缓存。不同转速仍可共用。
- “切到独立设置”保留原独立记录；“用当前有效条件建立独立记录”才执行明确复制。冲突、等待或未绑定时不可复制。
- 面积、N、转速、电解液气氛、扫描段、通道和 iR 不跟随。配对背景仍盘扣盘、环扣环。
- 旧项目保留旧策略和独立记录，可主动升级。参数 JSON 分开保存独立记录与有效条件，schema=2 项目需新版本读取。

## 简化条件与默认电极（1.3.0）

实验条件按绘图、K–L、RRDE 页面显示；三种电位换算方式只展示所需输入。高级扫描、通道、iR 和区间按需展开，必填项标注 `*`。

新文件默认使用 **直径 5 mm 的 RDE**，盘几何面积约 **0.19635 cm²**。电流密度和 K–L 可直接使用该默认面积，也可改直径或直接输入面积；计算保留未舍入值。已有项目和人工面积不会被新默认覆盖。新文件默认 pH 13、25 °C、SCE（饱和 KCl，E_ref vs SHE=0.241 V，仅适用于 25 °C）；RRDE N 默认 0.369，均可按实际实验修改。旧项目条件与空值保留。

常用条件保存与复用入口已移除。已有项目预设、本机预设文件和实验记录保留，不会因修改其他参数而清空；继续使用整份分析项目请下载 `.orrproj`。

K–L 可选择整套已有文献参数，也可自定义；不会从不明确的 Na 文件名自动推定 pH 或套用 KOH 参数。方案和默认值的来源会写入项目及参数 JSON。

已运行的服务关闭了文件监视。更新后先下载当前项目，再双击“停止 ORR.cmd”和“启动 ORR.cmd”载入新版。

## 文件名转速识别（1.2.0）

新导入时从原始文件名预填 rpm，明确转速标记优先，兼容原有末尾 2–5 位裸数字命名。相同明确候选去重；不同转速冲突、小数、负数或不支持的单位不会随意转换，会留空说明。`0转` 可记录静止实验，K–L 仍要求正转速。

默认分组会移除已识别的转速片段，保留浓度、扫描速率和其他命名信息。核对表保留转速来源和人工修改入口；转速识别详情展示区已删除，匹配依据与候选仍随参数和项目保存。

手动改值后请先点击“确认并应用分组与背景”。已经确认的人工值不会被绘图、重复导入或项目恢复覆盖。“根据文件名补全空白转速”只处理已应用配置中的空白值，保留非空值与分组。旧项目保留原转速和分组，来源未记录时如实标注。

详细验收规则和完成记录见 [转速任务文档](docs/tasks/RPM_FROM_FILENAME.md)。

## 可选曲线平滑（1.1.0）

极化页的“曲线平滑（仅绘图）”默认关闭。开启后使用 Savitzky–Golay 二阶局部多项式；弱/中/强窗口为 11/21/51 点，也可自定义 5–1001 的奇数点数。同图统一参数，逐条报告实际电位跨度。1 mV 步长下，三个预设的窗口首末跨度为 10/20/50 mV。

默认同时画浅色未平滑参考线，可隐藏。滤波端部采用 `mode="interp"`，端点仍可能改变或过冲；窗口越大，细节越可能丢失。

保留 NaN 缺口，只在连续有效段内处理。短于窗口的段、不等间距/重复/非单调电位段保留未平滑值并提示，不补点、不缩小窗口、不重采样。等间距判断公差为相对中位步长 1% 加 1e-9 V 数值公差。

**平滑不进入 K–L、RRDE 或背景扣除计算。** `polarization_data.csv` 保留全部原有列，启用时新增 `I_disk_smoothed_plot_only_A`、`I_disk_smoothed_plot_only_mA`、可选 `j_disk_smoothed_plot_only_mA_cm2` 和逐点 `smoothing_plot_status`。导出页的 `all_curves.csv` 始终是未平滑处理结果。

参数 JSON 记录平滑算法、窗口、阶数、跨度、缺口与跳过原因；`.orrproj` 保存开关、强度、自定义窗口和参考线设置。旧项目加载后默认关闭平滑。
